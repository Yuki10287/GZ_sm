# 任务三：从题目出发的规则提取框架

## 1. 任务三要解决的问题

任务二已经把成品油调价看作动态决策问题，并通过有限期滚动优化得到每个调价窗口下的最优执行动作。这个最优策略能够显著降低社会总福利损失，但它依赖多维状态变量、前瞻窗口和福利损失函数逐期求解，直接作为政策规则并不够简洁。

因此，任务三不应再重新构造一个更复杂的最优控制模型，而应解决一个“策略压缩”或“规则提取”问题：

> 在任务二滚动优化最优策略的基础上，提取一个低维、透明、可执行的简化调价规则，并检验该规则在国际油价不确定性下的鲁棒性。

换言之，任务二回答“理论上如何动态调价更优”，任务三回答“如何把复杂最优策略转化为可执行的政策机制”。

## 2. 规则提取的基本对象

任务二中，每期调价动作可以理解为对任务一理论机制调幅的比例执行：

```text
optimal_delta_t = ratio_t * mechanism_delta_t
```

其中：

- `mechanism_delta_t`：任务一第九版模型给出的现行机制理论调幅；
- `ratio_t`：任务二滚动优化选择的执行比例；
- 执行比例来自离散动作空间：

```text
ratio_grid = [0, 0.25, 0.5, 0.75, 1.0]
```

因此，任务三最自然的规则提取对象不是直接预测最终调价额，而是提取一个执行比例规则：

```text
ratio_t = f(累计调价压力, 成本安全压力, 油价波动状态, 前期调价路径)
```

然后由该比例规则生成简化调价额：

```text
rule_delta_t = ratio_t * cumulative_pressure_t
```

## 3. 简化规则应保留的核心机制

任务三的简化规则应从任务二最优策略中保留三类最重要的政策结构。

### 3.1 累计压力分档释放

任务一给出的理论调幅不应被理解为每期必须完全执行的行政指令，而应被理解为国际油价、汇率、便利收益和政策传导共同形成的“调价压力信号”。

定义累计调价压力：

```text
S_t = mechanism_delta_t + B_{t-1}
```

其中：

- `S_t`：第 t 期累计调价压力；
- `mechanism_delta_t`：第 t 期理论机制调幅；
- `B_{t-1}`：上一期未释放的结转压力。

根据累计压力绝对值大小，规则在暂缓、低比例、中比例、高比例、全额执行之间选择。

一个基础分档形式为：

| 累计压力区间 | 执行比例 |
|---|---:|
| `|S_t| < 50` | 0 |
| `50 <= |S_t| < theta_1` | 0.25 |
| `theta_1 <= |S_t| < theta_2` | 0.50 |
| `theta_2 <= |S_t| < theta_3` | 0.75 |
| `|S_t| >= theta_3` | 1.00 |

其中 50 元/吨门槛保留现行机制的政策基础，`theta_1`、`theta_2`、`theta_3` 由任务二最优策略反推，而不是主观设定。

### 3.2 未释放压力跨期结转

如果某期没有完全释放累计调价压力，则未执行部分进入下一期：

```text
B_t = S_t - rule_delta_t
```

结转项 `B_t` 相当于一个“调价压力缓冲账户”。它使政策规则既不会忽略国际油价变化，也不会被迫在单个窗口内完全释放全部压力。

这一结构对应任务二最优策略中的跨期缓冲特征，也是简化规则区别于现行机制的重要部分。

### 3.3 成本安全和高波动状态下的比例修正

仅靠累计压力分档还不够，因为调价决策还受到炼油企业合理利润、库存成本、供应安全和市场预期稳定的约束。

因此，在基础分档比例之上加入两个透明修正。

第一，成本安全修正。

当累计压力为负，即理论上应下调时，如果国内成品油价格接近成本和合理利润底线，则下调比例降低一档：

```text
if S_t < 0 and cost_security_pressure_t is high:
    ratio_t = max(ratio_t - 0.25, 0.25)
```

其政策含义是：下调不是不执行，而是避免一次性下调过大，导致价格过快低于库存成本和合理利润基础。

第二，波动平滑修正。

当国际油价处于高波动状态，或者前后调价方向频繁反转时，执行比例降低一档：

```text
if volatility_state_t is high or direction_reversal_t is true:
    ratio_t = max(ratio_t - 0.25, 0)
```

其政策含义是：在油价不确定性较强时，优先降低调价路径的弯折程度，稳定市场预期。

## 4. 规则参数如何从任务二中提取

任务三的关键不是拍脑袋设定阈值，而是构造一个可解释规则族，并用任务二相同的社会福利损失函数选择最优参数。

设简化规则的参数为：

```text
Theta = (theta_1, theta_2, theta_3, cost_threshold, volatility_threshold)
```

可以给出一个小规模、可解释的候选集合，例如：

```text
theta_1 in {100, 150, 200}
theta_2 in {250, 300, 350}
theta_3 in {450, 500, 600}
```

对每一组参数，生成一条简化规则调价路径，并代入任务二的五维社会福利损失函数：

```text
L_t = w_c * consumer_loss_t
    + w_p * profit_loss_t
    + w_i * cpi_loss_t
    + w_e * expectation_loss_t
    + w_s * security_loss_t
```

规则参数选择问题写成：

```text
min_Theta sum_t L_t(rule_delta_t(Theta))
```

这样，任务三的规则提取就是：

> 在一个透明、低维、可执行的政策规则族中，寻找能够最大程度保留任务二福利改进的参数组合。

## 5. 简化规则和任务二最优策略的关系

任务三不能把简化规则说成新的全局最优策略。更准确的表述是：

- 任务二滚动优化策略是“教师策略”；
- 任务三简化规则是“学生规则”；
- 简化规则通过分档、结转和修正项近似任务二的最优调价逻辑；
- 简化规则牺牲一部分精细度，换取透明性、稳定性和政策可执行性。

因此，论文中应强调：

> 简化规则不是替代任务二理论模型，而是将任务二最优策略转化为可操作政策机制的近似表达。

## 6. 规则提取后的评价指标

提取规则后，应从三类指标检验其效果。

### 6.1 对最优策略的近似能力

主要看简化规则是否保留了任务二最优策略的动作特征：

- 执行比例匹配率；
- 调价方向一致率；
- 平均调幅误差；
- 大幅调价次数；
- 调价路径平滑程度。

### 6.2 对福利改进的保留能力

比较三条路径：

1. 现行机制；
2. 任务二滚动优化最优策略；
3. 任务三简化规则。

核心判断不是简化规则是否完全等同于任务二最优策略，而是它是否满足：

```text
loss_optimal < loss_rule < loss_current
```

并且：

```text
(loss_current - loss_rule) / (loss_current - loss_optimal)
```

能够说明简化规则保留了多少任务二最优策略带来的福利改进。

### 6.3 政策可执行性

简化规则还需要证明其政策可操作性：

- 是否保留 10 个工作日窗口；
- 是否保留 50 元/吨调价门槛；
- 是否兼容 40 美元地板价和 130 美元天花板价；
- 是否只依赖可公开获取或监管部门可观测的变量；
- 是否能用分档表格解释；
- 是否能在高波动时期自动降低调价强度。

## 7. 与鲁棒性检验的衔接

规则提取完成后，任务三第二步应进入鲁棒性检验。

鲁棒性检验的对象不是任务二复杂最优策略，而是刚提取出的简化规则。

可以构造多种国际油价不确定性情景：

- 基准波动情景；
- 高波动情景；
- 单边上涨冲击；
- 单边下跌冲击；
- 先涨后跌或先跌后涨的反转冲击；
- 极端油价冲击情景。

在每种情景下比较：

- 现行机制；
- 简化规则；
- 必要时加入任务二最优策略作为理论上界。

核心问题是：

> 简化规则是否在不同油价波动情景下仍然保持较低福利损失、较少大幅调价和较平滑的价格路径？

## 8. 当前建议的任务三主线

任务三可以按以下逻辑展开：

1. 说明任务二最优策略虽然福利表现较好，但直接执行成本高、解释难度大。
2. 将任务二最优策略视为复杂教师策略。
3. 构造一个低维学生规则：累计压力分档释放 + 跨期结转 + 成本安全修正 + 波动平滑修正。
4. 使用任务二同一福利损失函数，在可解释参数空间中选择规则参数。
5. 比较现行机制、任务二最优策略和任务三简化规则的损失与调价特征。
6. 在国际油价不确定性情景下检验简化规则鲁棒性。
7. 基于检验结果提出政策建议。

用一句话概括：

> 任务三不是重新求一个更复杂的最优策略，而是把任务二复杂动态策略提炼为“分档释放、跨期结转、成本约束、波动降档”的可执行调价规则，并检验其在不确定油价环境下的稳健性。

## 9. 建议作为任务三最终主方案的规则

结合题目要求和任务一、任务二已有求解结果，建议任务三最终采用以下方案作为主答案：

> 构建“累计压力缓冲账户下的分档比例调价规则”，并通过任务二社会福利损失函数反推规则参数。

这个方案比纯机器学习规则更适合作为论文主模型，原因有三点：

1. 它继承了现行机制的基本制度框架，包括 10 个工作日调价窗口、50 元/吨调价门槛、地板价和天花板价；
2. 它直接吸收任务二最优策略的三个核心特征，即分档释放、跨期缓冲和成本约束下的非对称调节；
3. 它足够透明，可以用分档表和少量判断条件表达，符合题目对“简洁、透明、可操作规则”的要求。

因此，不建议把决策树、随机森林或其他黑箱分类模型作为任务三主模型。它们可以作为附加验证，但不适合承担政策规则主体。任务三的主模型应是一个可解释的制度化调价规则。

### 9.1 最终规则结构

第 t 个调价窗口，先计算累计调价压力：

```text
S_t = Delta_t^M + B_{t-1}
```

其中：

- `Delta_t^M` 为任务一第九版模型得到的现行机制理论调幅；
- `B_{t-1}` 为上一期未释放的调价压力。

然后根据累计压力绝对值确定基础执行比例：

| 累计压力区间 | 基础执行比例 |
|---|---:|
| `|S_t| < 50` | 0 |
| `50 <= |S_t| < theta_1` | 0.25 |
| `theta_1 <= |S_t| < theta_2` | 0.50 |
| `theta_2 <= |S_t| < theta_3` | 0.75 |
| `|S_t| >= theta_3` | 1.00 |

基础调价额为：

```text
A_t^0 = r_t^0 * S_t
```

其中 `r_t^0` 是基础执行比例。

### 9.2 成本安全修正

任务二结果显示，最优策略的总损失下降主要来自价格预期平滑损失下降，但消费者福利、企业利润保障和能源安全损失并非全部同步下降。这说明调价规则不能只追求平滑，也要保留成本与供应约束。

因此，当累计压力为负、规则倾向下调时，需要检查成本安全状态。如果国内价格接近库存成本和合理利润底线，则下调比例降低一档：

```text
if S_t < 0 and cost_margin_t < kappa:
    r_t = max(r_t^0 - 0.25, 0.25)
else:
    r_t = r_t^0
```

其中 `cost_margin_t` 可由任务二中的成本和合理利润变量构造，`kappa` 是成本安全阈值。

该修正反映任务二得到的“成本约束下的非对称调节”：上调时保留必要成本传导，下调时避免过快压缩企业合理利润和供应安全空间。

### 9.3 波动平滑修正

当国际油价波动较高，或连续窗口调价方向频繁反转时，应降低执行比例一档：

```text
if volatility_t > nu or direction_reversal_t == 1:
    r_t = max(r_t - 0.25, 0)
```

其中：

- `volatility_t` 可取国际油价状态或 Brent 价格的滚动波动率；
- `nu` 为高波动阈值；
- `direction_reversal_t` 表示调价方向是否发生反转。

这一修正对应任务二中的价格预期平滑损失。由于任务二结果表明最优策略相对于现行机制的主要改进来自预期平滑损失大幅下降，因此任务三简化规则必须显式保留“高波动降档”和“反转降档”机制。

### 9.4 最终调价额和结转账户

修正后的最终执行比例为 `r_t`，最终调价额为：

```text
A_t = r_t * S_t
```

未释放压力进入下一期：

```text
B_t = S_t - A_t
```

如果 `|A_t| < 50`，则本期不实际调价，全部压力继续结转：

```text
if |A_t| < 50:
    A_t = 0
    B_t = S_t
```

这个结转账户是任务三规则的核心。它使规则不同于简单削峰填谷：没有释放的调价压力不会消失，而是进入后续窗口，等待压力累积到更合适的释放区间。

### 9.5 参数确定方法

参数包括：

```text
Theta = (theta_1, theta_2, theta_3, kappa, nu)
```

建议不使用连续优化，而使用小规模网格搜索。原因是任务三强调政策透明性，参数应来自若干易解释的候选值，而不是难以解释的高精度数值。

参数选择准则为：

```text
min_Theta sum_t L_t(A_t(Theta))
```

其中 `L_t` 使用任务二相同的五维社会福利损失函数。

如果多个参数组合的损失接近，应优先选择更简单、更容易解释、更接近现行政策口径的参数。例如阈值优先选择 100、200、300、500 这类整数档，而不是非常细碎的数值。

### 9.6 论文中应给出的核心结论形式

任务三最终应形成如下结论：

> 在任务二滚动优化策略基础上，本文提取出一种累计压力缓冲账户下的分档比例调价规则。该规则以现行机制理论调幅为压力信号，通过 0、25%、50%、75% 和 100% 五档执行比例释放调价压力，并将未释放部分跨期结转；同时，在成本安全压力较高或国际油价高波动时降低执行比例，以兼顾市场预期稳定、企业合理利润和供应安全。参数由任务二社会福利损失函数在可解释参数空间内反推确定。

这个方案可以作为任务三的主模型答案。后续鲁棒性检验就围绕这一条简化规则展开，而不是再重新寻找另一套规则。
