# 任务三：面向公众解释和政策执行的简化规则提取方案

## 1. 对任务三的重新定位

任务三的核心不是在任务二之后再建立一个新的复杂优化模型，而是把任务二得到的动态最优调价策略转化为公众容易理解、政策部门容易执行的简化规则。

任务二的滚动优化策略能够给出较优的调价路径，但它依赖五维社会福利损失函数、前瞻窗口、离散动作空间和跨期状态更新。这样的策略适合用于理论分析，但不适合直接作为政策公告或实际执行规则。

因此，任务三应理解为：

> 对任务二复杂动态策略进行规则化、通俗化和稳健性检验。

具体来说，任务三要回答三个问题：

1. 任务二最优策略中有哪些可以被公众理解的稳定规律？
2. 这些规律能否整理成一套简洁、透明、可执行的调价规则？
3. 这套简化规则在国际油价不确定波动下是否仍然稳健？

## 2. 从任务二策略中提取哪些规律

任务二滚动优化结果不应被直接照搬为政策规则，而应从中提取可解释特征。结合任务二已有结果，最值得保留的是三类规律。

### 2.1 理论调幅不是必须全额执行，而是调价压力信号

现行机制倾向于根据国际油价变化形成理论调幅，达到门槛后进行调整。任务二最优策略表明，理论调幅不必每期完全执行，而可以理解为一项“调价压力”。

如果压力较小，可以暂缓；如果压力中等，可以部分释放；如果压力很大，则需要较高比例释放。

这一点可以通俗表述为：

> 国际油价变化先形成调价压力，国内价格不机械跟随，而是根据压力大小分档释放。

### 2.2 未释放压力不消失，而是进入缓冲账户

如果某一期没有完全释放理论调价压力，任务二策略并不是把这部分压力忽略掉，而是允许它影响后续窗口。

因此，简化规则中应设置一个“缓冲账户”：

```text
本期累计压力 = 本期新增压力 + 上期未释放压力
```

通俗解释是：

> 该调但没完全调的部分先记账，之后根据油价走势和压力大小逐步释放。

这既避免了一次性大幅调价，也避免长期压制价格信号。

### 2.3 高波动和成本压力下要降低调价强度

任务二五维损失分解显示，最优策略相对于现行机制的主要改进来自价格预期平滑损失的大幅下降，而不是五个损失维度全部同时下降。

这说明简化规则不能追求“每一项都更好”，而应承认它是在多目标之间做折中：

- 为稳定预期，需要减少价格路径的大起大落；
- 为保障供应，需要避免下调过快压缩企业合理利润；
- 为保护民生，也不能长期积累过大的上调压力。

因此，规则中应加入两类容易解释的降档条件：

1. 国际油价高波动时，调价比例降低一档；
2. 下调时若接近成本和合理利润底线，下调比例降低一档。

## 3. 简化规则的最终形式

基于以上规律，任务三可将任务二策略提炼为：

> 累计压力缓冲账户下的分档比例调价规则。

该规则由四句话概括：

1. 先计算累计调价压力；
2. 按压力大小分档释放；
3. 未释放压力进入下一期缓冲账户；
4. 高波动或成本安全压力较高时降低一档执行比例。

## 4. 规则步骤

### 4.1 计算累计调价压力

第 t 个调价窗口，设：

```text
Delta_t^M = 任务一模型得到的理论机制调幅
B_{t-1} = 上一期未释放的调价压力
S_t = 本期累计调价压力
```

则：

```text
S_t = Delta_t^M + B_{t-1}
```

其中初始缓冲账户：

```text
B_0 = 0
```

### 4.2 按压力大小确定基础执行比例

保留现行机制 50 元/吨调价门槛，并将累计压力划分为五档：

| 累计压力大小 | 基础执行比例 | 政策含义 |
|---|---:|---|
| `|S_t| < 50` | 0 | 压力较小，暂不调价 |
| 小幅压力 | 25% | 少量释放，避免频繁跳动 |
| 中等压力 | 50% | 均衡释放，兼顾传导和平滑 |
| 较大压力 | 75% | 加快释放，避免压力过度累积 |
| 极大压力 | 100% | 充分释放，防止价格严重偏离成本 |

为了保持规则简洁，论文中可以不强调具体阈值的精细最优性，而是将阈值作为根据任务二结果校准得到的政策参数。

### 4.3 成本安全降档

当累计压力为负，即规则倾向下调时，如果价格已经接近成本和合理利润底线，则下调比例降低一档。

```text
如果 S_t < 0 且成本安全边际偏低：
    执行比例降低一档
```

例如：

```text
50% -> 25%
75% -> 50%
100% -> 75%
```

但已经达到最低执行档时，不再继续降低，以免完全阻断正常下调。

通俗解释是：

> 油价下跌可以传导给消费者，但不能一次性下调过快，以免冲击炼油企业合理利润和供应稳定。

### 4.4 高波动降档

当国际油价处于高波动状态，或者调价方向连续反转时，执行比例降低一档。

```text
如果国际油价高波动，或调价方向频繁反转：
    执行比例降低一档
```

通俗解释是：

> 当外部油价还在剧烈摇摆时，国内价格不应过度追随短期波动，而应适当放慢调整节奏。

### 4.5 更新缓冲账户

最终调价额为：

```text
A_t = r_t * S_t
```

未释放压力进入下一期：

```text
B_t = S_t - A_t
```

如果最终调价额仍小于 50 元/吨，则本期不实际调价，压力全部结转：

```text
如果 |A_t| < 50：
    A_t = 0
    B_t = S_t
```

## 5. 参数如何确定：从“优化求解”改为“规则校准”

任务三不宜表述为重新建立复杂优化模型。更合适的说法是：

> 根据任务二最优策略的动作特征，对简化规则参数进行校准。

具体做法可以是：

1. 先根据任务二最优动作分布，观察不同累计压力区间对应的常见执行比例；
2. 将压力区间整理为少数几个容易解释的阈值档；
3. 用任务二社会福利损失函数检验候选阈值是否合理；
4. 若多个阈值组合表现接近，优先选择更简单、更容易解释的整数阈值。

因此，任务二损失函数在任务三中的作用不是重新求最优策略，而是作为“筛选尺子”：

```text
它用于验证简化规则是否仍然保留任务二策略的大部分福利改进。
```

论文中可写为：

> 为避免简化规则完全依赖主观归纳，本文利用任务二社会福利损失函数对候选规则进行校准和筛选，但规则主体仍保持分档表形式，以保证透明性和可执行性。

## 6. 任务三不应强调什么

为了和题目要求保持一致，任务三中应避免以下表达：

1. 不应说“重新构建最优动态调价模型”。
2. 不应说“再次求解全局最优策略”。
3. 不应把决策树、随机森林等黑箱拟合作为主规则。
4. 不应把简化规则说成比任务二策略更优。

更合适的表达是：

1. “从任务二最优策略中提取可解释规律”；
2. “将复杂动态策略转化为分档规则”；
3. “对规则参数进行轻量校准”；
4. “检验简化规则在不确定情景下的鲁棒性”。

## 7. 规则有效性的评价

简化规则提出后，需要说明它是否足够接近任务二策略，并且是否优于现行机制。

建议比较三条路径：

1. 现行机制路径；
2. 任务二滚动优化策略路径；
3. 任务三简化规则路径。

评价指标包括：

- 平均社会总福利损失；
- 五维损失分解；
- 平均绝对调幅；
- 大幅调价次数；
- 调价方向反转次数；
- 价格路径平滑程度；
- 简化规则保留任务二福利改进的比例。

其中，最重要的判断关系是：

```text
任务二最优策略损失 <= 任务三简化规则损失 <= 现行机制损失
```

如果该关系成立，就可以说明：

> 简化规则虽然牺牲了一部分精细度，但保留了任务二复杂策略的大部分改进，同时显著提高了透明度和可执行性。

## 8. 鲁棒性检验如何接上

任务三后半部分应围绕简化规则做鲁棒性检验，而不是继续优化规则。

可以构造若干国际油价不确定性情景：

| 情景 | 含义 |
|---|---|
| 基准波动 | 油价按历史平均波动水平变化 |
| 高波动 | 油价波动率显著升高 |
| 单边上涨 | 国际油价持续上涨 |
| 单边下跌 | 国际油价持续下跌 |
| 反转冲击 | 油价先涨后跌或先跌后涨 |
| 极端冲击 | 出现类似地缘风险或金融危机的异常波动 |

在每个情景下比较现行机制和简化规则的表现，重点看：

- 是否减少大幅调价；
- 是否降低价格路径弯折程度；
- 是否避免福利损失显著恶化；
- 是否在高波动时期保持政策稳定性。

鲁棒性检验的结论不必要求简化规则在每个单项指标上都占优，而应强调：

> 在多数不确定情景下，简化规则能够以较低执行复杂度保持接近任务二最优策略的福利表现，并优于机械执行的现行机制。

## 9. 可直接用于论文的写法

任务二滚动优化模型虽然能够给出较优的动态调价路径，但其决策过程涉及多维福利损失函数和跨期前瞻计算，直接作为政策规则不够简洁透明。为此，任务三不再重新构建复杂优化模型，而是从任务二最优策略中提取稳定、可解释的动作规律，将其转化为面向公众解释和政策执行的简化规则。

具体而言，本文将任务一得到的理论机制调幅视为调价压力信号，并设置跨期缓冲账户记录未释放压力。在每个调价窗口，先由本期理论调幅和上一期未释放压力形成累计调价压力，再根据压力大小在 0、25%、50%、75% 和 100% 五档执行比例之间选择。若本期调价额低于 50 元/吨门槛，则不实际调价并将压力继续结转。进一步地，当下调可能压缩成本和合理利润安全边际时，规则降低下调比例；当国际油价处于高波动或调价方向频繁反转时，规则降低执行比例，以稳定市场预期。

该规则可以概括为“累计压力缓冲账户下的分档比例调价规则”。其政策含义是：国际油价变化不再被机械地一次性传导为国内价格调整，而是先形成调价压力，再按照压力大小和市场状态分档释放。未释放部分并不消失，而是进入后续窗口逐步释放。这样既保留了价格对国际成本变化的响应，又降低了短期剧烈波动对消费者预期、企业经营和供应安全的冲击。

为避免规则完全依赖主观设定，本文进一步利用任务二得到的最优调价路径和社会福利损失函数对候选分档阈值进行轻量校准。这里的校准并不是重新求解新的最优控制问题，而是检验简化规则是否能够保留任务二复杂策略的大部分福利改进。最终，通过比较现行机制、任务二滚动优化策略和任务三简化规则的福利损失、调价幅度和价格平滑性，评估简化规则的有效性，并在不同国际油价波动情景下检验其鲁棒性。
