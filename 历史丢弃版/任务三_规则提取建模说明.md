# 任务三：最优策略的简化规则提取模型

任务三的核心不是重新求解一个新的最优调价模型，而是将任务二得到的滚动优化策略压缩为一套简洁、透明、可执行的调价规则。由于任务二的滚动优化策略依赖多维状态变量和逐期枚举搜索，直接作为政策规则不便解释。因此，本文将任务二最优策略视为“教师策略”，通过规则提取方法构造一个可公开说明的近似策略。

## 一、规则提取的基本思想

设任务一机制模型给出的理论调幅为：

```text
ΔP_t^m
```

设上一期未执行并结转至本期的调价压力为：

```text
C_t
```

则本期可供政策执行的综合调价信号定义为：

```text
S_t = ΔP_t^m + C_t
```

其中，`S_t > 0` 表示上调压力，`S_t < 0` 表示下调压力。规则提取的目标不是重新预测油价，而是根据 `S_t` 的大小和方向决定实际释放比例 `r_t`，从而得到本期实际调幅：

```text
a_t = r_t S_t
```

若实际调幅低于 50 元/吨，则本期不执行，并将全部信号结转至下一期。

## 二、规则形式设定

为了保证规则简洁，本文将执行比例限制为少数几个透明档位：

```text
r_t ∈ {0, 0.25, 0.50, 0.75, 1.00}
```

规则首先根据信号强度分档：

```text
若 |S_t| < 50，则 r_t = 0；
若 50 ≤ |S_t| < A，则 r_t = 0.25；
若 A ≤ |S_t| < B，则 r_t = 0.50；
若 |S_t| ≥ B，则 r_t = 0.75。
```

其中 `A` 和 `B` 为待识别的信号强度阈值。这样处理的含义是：理论调幅越大，说明外部油价压力越强，规则释放的比例也越高；但即使压力较大，也不默认一次性全额执行，从而保留平滑空间。

## 三、成本压力修正

仅依据信号强度分档，可能忽略炼油企业成本覆盖和供应安全问题。因此，本文进一步引入成本压力指标：

```text
pressure_t =
[inventory_cost_t(1 + margin_target) - P_{t-1}] / inventory_cost_t
```

其中 `inventory_cost_t` 表示库存成本，`margin_target` 表示目标合理利润率，`P_{t-1}` 表示上期国内成品油价格。当 `pressure_t` 较大时，说明国内价格低于成本加合理利润区间，存在利润不足或供应安全压力。

因此，设成本压力阈值为 `D`，规则修正为：

```text
若 pressure_t > D 且 S_t > 0，则执行比例提高 0.25；
若 pressure_t > D 且 S_t < 0，则执行比例降低 0.25。
```

该修正使规则具有非对称调节特征：成本压力较高时，上调更充分、下调更谨慎，从而避免价格平滑过度损害供应稳定。

## 四、规则参数识别

规则中需要识别的参数为：

```text
θ = (A, B, D)
```

其中 `A` 为低信号阈值，`B` 为高信号阈值，`D` 为成本压力阈值。本文采用网格搜索方法，从候选参数集合中选择表现最优的规则。

参数识别的目标不是单纯追求与任务二最优策略完全一致，而是在“可解释性”和“福利表现”之间折中。因此，评价准则包括：

```text
1. 简化规则回放下的平均社会总福利损失较低；
2. 规则调价方向尽量接近任务二滚动最优策略；
3. 调价幅度不过度放大；
4. 结转规模保持可控；
5. 规则形式足够简单，便于政策解释。
```

在实际计算中，以任务二滚动优化策略为参照，对候选阈值组合进行历史回放，计算每组参数下的福利损失、方向匹配率、执行比例匹配率和结转规模。最终选取得到：

```text
A = 80，B = 420，D = 0.06。
```

此时，规则与任务二滚动最优策略的调价方向匹配率为 80.5%，执行比例匹配率为 31.5%。方向匹配率较高说明简化规则较好保留了最优策略的基本调价方向；比例匹配率较低是规则简化带来的结果，说明它并不逐期复制最优策略，而是将复杂动态优化策略压缩为少数可解释档位。

## 五、最终提取规则

综上，本文从任务二最优策略中提取出的简化调价规则为：

```text
S_t = ΔP_t^m + C_t

若 |S_t| < 50：
    不调价，全部结转；

若 50 ≤ |S_t| < 80：
    基础执行比例为 25%；

若 80 ≤ |S_t| < 420：
    基础执行比例为 50%；

若 |S_t| ≥ 420：
    基础执行比例为 75%；

若 pressure_t > 0.06 且 S_t > 0：
    执行比例提高 25 个百分点；

若 pressure_t > 0.06 且 S_t < 0：
    执行比例降低 25 个百分点。
```

最终实际调幅为：

```text
a_t = r_t S_t
```

若 `|a_t| < 50`，则本期实际调幅为 0，并将未执行部分结转至下一期：

```text
C_{t+1} = S_t
```

若 `|a_t| ≥ 50`，则执行 `a_t`，剩余部分结转：

```text
C_{t+1} = S_t - a_t
```

该规则保留了任务二最优策略的三个关键思想：一是理论调幅分档执行，二是未执行调幅跨期结转，三是成本压力下进行非对称修正。因此，它可以作为任务三后续鲁棒性检验和政策建议部分的基础规则。
