真实 M1/M3/M6 期限结构增强双因子状态空间模型说明
====================================================

一、这一版做了什么

本版是在之前 Gemini 提出的“双因子状态空间模型改进方向”基础上，加入队友新补充的真实期货期限结构数据后完成的一版实验。

之前我们做过一版“把 WTI 的期限结构比例迁移到 Brent 和 Dubai 上”的代理实验，但那一版 Brent/Dubai 的期限结构并不是真实市场数据。本版改用队友提供的真实数据：

- Brent 原油 M1、M3、M6；
- Dubai 原油 M1、M3、M6；
- WTI 原油 M1、M3、M6。

数据文件来自：

    期货数据/futuredata.xlsx

时间范围为：

    2016-01-29 至 2026-04-30

本版代码文件为：

    task1_real_m136_gemini.py

结果输出目录为：

    outputs/task1_real_m136_gemini


二、为什么要这样建模

队友最初的双因子模型希望把国际油价分解为两个潜在状态：

    X_t：基础油价水平
    delta_t：便利收益或期限结构压力

这个思想本身有经济学依据，但如果只使用 Brent、WTI、Dubai 三条现货价格序列，会有一个严重问题：

    三条现货价格高度同步，信息维度太低，模型很难稳定识别 delta_t。

因此 Gemini 建议引入期货期限结构数据。原因是：

    便利收益通常体现在近月合约和远月合约之间的价差中。

如果近月价格明显高于远月价格，市场可能处于现货偏紧或 backwardation 状态；
如果远月价格高于近月价格，则可能体现 contango 状态。

所以，真实的 M1、M3、M6 期货数据比单纯的现货价格更适合帮助识别 delta_t。


三、模型具体怎么建

本版仍然保留双因子状态空间结构。

状态变量为：

    s_t = [X_t, delta_t]'

其中：

    X_t 表示基础国际油价水平；
    delta_t 表示期限结构压力或便利收益因素。

状态转移方程大致为：

    X_t 由上一期 X_{t-1} 和 delta_{t-1} 推动；
    delta_t 按均值回复过程变化。

为了降低参数识别难度，本版仍固定噪声相关系数：

    rho = 0

这也是之前 Gemini 建议中的“参数固定/校准”思想，目的是减少极大似然估计的搜索维度。


四、观测方程如何设计

这版没有简单把 9 条期货价格水平全部直接放进模型。

原因是 M1、M3、M6 本身价格水平高度相关，直接堆进去会造成严重共线性，模型容易把价格水平变化和期限结构变化混在一起。

所以本版把观测变量分成两类。

第一类：价格水平变量

    log(Brent)
    log(WTI)
    log(Dubai)

这些变量主要用于识别基础油价水平 X_t。

第二类：期限价差变量

    log(Brent_M1 / Brent_M3)
    log(Brent_M1 / Brent_M6)
    log(Brent_M3 / Brent_M6)

    log(Dubai_M1 / Dubai_M3)
    log(Dubai_M1 / Dubai_M6)
    log(Dubai_M3 / Dubai_M6)

    log(WTI_M1 / WTI_M3)
    log(WTI_M1 / WTI_M6)
    log(WTI_M3 / WTI_M6)

这些变量主要用于识别 delta_t。

这样做的好处是：

    价格水平负责解释“油价整体贵不贵”；
    期限价差负责解释“近远月结构是否异常”；
    两类信息在状态空间模型里分工更清楚。


五、如何避免未来信息泄露

队友提供的 M1/M3/M6 数据是月度数据，基本是月末数据。

如果把月度数据线性插值到日度，会出现一个问题：

    月中日期会提前用到未来月末价格。

这会造成未来信息泄露。

因此本版采用保守处理：

    某个月末的期货数据，只从该月末开始向后填充；
    在下一期月末数据出现之前，都使用最近已经可获得的一期数据；
    不做线性插值。

这种处理更符合“调价日前已经可以获得的最近一期数据”的建模要求。


六、国内调价机制层如何处理

状态空间模型估计出基础油价指数后，还要进入国内成品油调价机制层。

这一层沿用我们之前修正后的机制规则：

1. 使用本调价周期 10 个工作日均价；
2. 与上一调价周期 10 个工作日均价比较；
3. 设置 1 天计价滞后；
4. 50 元/吨门槛使用硬截断；
5. 40 美元和 130 美元政策边界使用硬规则；
6. 再结合汇率、桶吨换算、税费系数，得到汽油和柴油理论调价幅度。

也就是说，本版的改进重点在“国际油价状态识别层”，国内调价规则层仍使用我们之前验证过的修正版。


七、运行结果

全样本有效调价窗口：

    n = 198

全样本结果：

    汽油 MAE = 114.58 元/吨
    柴油 MAE = 112.37 元/吨
    汽油方向准确率 = 79.29%
    柴油方向准确率 = 76.77%

2023 年以后测试期：

    汽油 MAE = 152.26 元/吨
    柴油 MAE = 137.27 元/吨
    汽油方向准确率 = 78.79%
    柴油方向准确率 = 77.27%


八、为什么全样本 MAE 被拉高

分年份检查后发现，2026 年 3-4 月的数据对结果影响很大。

尤其是 2026-03-24 这一期，模型给出的汽油理论调价达到：

    4548 元/吨

这明显高于实际调价幅度，导致全样本 MAE 和 RMSE 被显著拉高。

这个异常主要来自 2026 年 3-4 月真实期货期限结构中的极端跳变。

剔除 2026 年以后，结果明显正常很多。

2016-2025：

    汽油 MAE = 89.06 元/吨
    柴油 MAE = 92.38 元/吨

2023-2025：

    汽油 MAE = 74.13 元/吨
    柴油 MAE = 75.52 元/吨


九、和已有版本的比较

同样看 2023-2025 这个更稳定的比较区间：

修正机制层后的现货双因子模型：

    汽油 MAE = 74.67
    柴油 MAE = 64.81

PCA/Kalman 优化机制模型：

    汽油 MAE = 70.59
    柴油 MAE = 70.84

本版真实 M1/M3/M6 期限结构模型：

    汽油 MAE = 74.13
    柴油 MAE = 75.52

可以看到，本版汽油效果接近现有较好模型，但柴油效果没有超过现货双因子修正版，也没有稳定超过 PCA/Kalman 优化机制模型。


十、总体评价

本版的意义在于：

    它证明真实期限结构数据确实比简单堆现货价格更有经济含义；
    也比队友直接把 M1/M3/M6 价格水平全部放入模型的版本更稳；
    但目前还没有稳定超过我们之前效果最好的主力模型。

因此，这版更适合在论文中作为“期限结构扩展实验”或“便利收益识别改进实验”。

不建议把它作为最终主模型。

更稳妥的论文表述是：

    在双因子状态空间模型基础上，本文进一步引入 Brent、Dubai、WTI 的 M1/M3/M6 真实期货期限结构。
    为避免价格水平共线性，本文将期货数据转换为近远月价差观测项，用于增强对期限结构压力因子 delta_t 的识别。
    实验表明，真实期限结构信息能够改善双因子模型的经济解释性，但由于 2026 年部分期限结构数据出现异常跳变，模型整体稳定性仍弱于本文主模型。

最终建议：

    主模型继续使用之前效果更稳定的多源动态因子状态空间模型或修正机制层后的现货双因子模型；
    本版作为补充实验，用来说明真实期货期限结构对识别便利收益或成本压力因子具有一定帮助。
