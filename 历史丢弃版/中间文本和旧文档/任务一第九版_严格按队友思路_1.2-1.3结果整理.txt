任务一第九版模型：严格依据队友 1.2-1.3 思路的结果整理
============================================================

说明：
本文件严格按照《任务一 5.12 18点.docx》中 1.2 和 1.3 的原始建模思路整理。

与上一版整理的区别：
上一版使用的是“理论调价幅度 -> 实际调价幅度”的政策传导检验；
本版严格回到队友文档中的 NARDL 思路，即：
1.2 做短期非对称性检验和长期非对称性检验；
1.3 按低油价区间、正常油价区间、高油价区间三个制度区间讨论。


一、1.2 价格传递不对称性的检验结果
------------------------------------------------------------

1. 原文档建模思路

队友原文档中 1.2 的核心思想是使用 NARDL 模型。
NARDL 的关键在于将国际油价变化拆分为上涨累计项和下跌累计项：

X_t^+ = Σ max(ΔX_t, 0)
X_t^- = Σ min(ΔX_t, 0)

其中，X_t 表示国际真实油价信号。
在第九版模型中，本文使用双因子状态空间模型得到的综合国际油价窗口均值作为 X_t 的代理变量。
国内价格变量使用汽油、柴油价格水平。

NARDL 误差修正形式可以写为：

ΔY_t = c + ρY_{t-1} + θ^+X_{t-1}^+ + θ^-X_{t-1}^-
       + Σφ_iΔY_{t-i} + Σπ_i^+ΔX_{t-i}^+ + Σπ_i^-ΔX_{t-i}^- + ε_t

其中：
Y_t 表示国内汽油或柴油价格；
X_t^+ 表示国际油价上涨累计项；
X_t^- 表示国际油价下跌累计项。

短期非对称性检验：
H_0: Σπ_i^+ = Σπ_i^-

长期非对称性检验：
H_0: -θ^+/ρ = -θ^-/ρ

本文使用 BIC 在滞后阶数中进行选择，最终汽油和柴油均选择 p=1, q=1。


2. 短期非对称性检验结果

品种    样本数    最优滞后(p,q)    短期上涨效应    短期下跌效应    Wald检验p值    结论
汽油    198       (1,1)           0.507           0.592           0.3461        不拒绝短期对称
柴油    198       (1,1)           0.585           0.696           0.2724        不拒绝短期对称

结果分析：
汽油短期 Wald 检验 p 值为0.3461，柴油短期 Wald 检验 p 值为0.2724，均大于0.10。
因此，按照 NARDL 的短期非对称性检验，不能拒绝“短期上涨和下跌传导对称”的原假设。

这说明在一个或两个调价周期的短期范围内，国内成品油价格对国际油价上涨和下跌冲击的即时响应差异并不显著。
也就是说，短期内没有充分统计证据证明存在明显的“涨快跌慢”或“涨慢跌快”。


3. 长期非对称性检验结果

品种    样本数    最优滞后(p,q)    长期上涨系数    长期下跌系数    Wald检验p值    R²       结论
汽油    198       (1,1)           0.586           0.600           0.1103        0.922    不拒绝长期对称
柴油    198       (1,1)           0.636           0.650           0.1341        0.907    不拒绝长期对称

结果分析：
汽油长期 Wald 检验 p 值为0.1103，柴油长期 Wald 检验 p 值为0.1341，均大于0.10。
因此，按照 NARDL 的长期非对称性检验，也不能拒绝“长期上涨和下跌传导对称”的原假设。

从长期系数看，汽油上涨系数为0.586，下跌系数为0.600；
柴油上涨系数为0.636，下跌系数为0.650。
两类成品油的长期上涨、下跌系数数值接近，这说明从长期均衡关系看，国内成品油价格总体仍围绕国际油价成本信号调整。


4. 1.2 结论

严格按照队友原文档中的 NARDL 思路进行检验后，结果显示：

（1）短期非对称性不显著。
汽油和柴油的短期 Wald 检验 p 值分别为0.3461和0.2724，均不能拒绝短期对称传导假设。

（2）长期非对称性也不显著。
汽油和柴油的长期 Wald 检验 p 值分别为0.1103和0.1341，均不能拒绝长期对称传导假设。

（3）因此，若严格采用 NARDL 框架，本文不能得出“我国成品油价格存在显著涨跌非对称传导”的结论。

（4）更稳妥的论文表述应为：
在双因子状态空间模型提取的国际真实油价基础上，NARDL 检验显示，样本期内汽油和柴油价格对国际油价上涨与下跌的短期、长期响应差异均未达到统计显著水平。这表明现行机制在长期成本传导上具有一定对称性，价格调控的差异更多体现在特殊油价区间和政策平滑幅度上，而非稳定的“涨多跌少”结构。


二、1.3 定价机制在不同国际油价区间的表现特征
------------------------------------------------------------

1. 原文档建模思路

队友原文档中 1.3 的核心思想不是任意划分多个油价段，而是依据《石油价格管理办法》中的两个制度边界：

低油价区间：国际油价低于40美元/桶，触发地板价约束；
高油价区间：国际油价高于130美元/桶，触发天花板价约束；
正常油价区间：国际油价位于40美元/桶至130美元/桶之间。

因此，本版严格使用三个区间：

（1）低油价区间：MA_t < 40；
（2）正常油价区间：40 <= MA_t < 130；
（3）高油价区间：MA_t >= 130。

其中 MA_t 为第九版模型中计算得到的调价窗口综合国际油价移动平均值。

样本期内：
最低窗口均价为36.82美元/桶；
最高窗口均价为123.52美元/桶。

因此，样本中存在低油价地板价窗口，但不存在130美元/桶以上的高油价天花板窗口。


2. 三个区间的统计结果

3. 低油价区间分析

低油价区间共有3个调价窗口，分别出现在2020年3月18日、2020年9月19日和2020年11月6日。
这三个窗口的综合国际油价均低于40美元/桶，触发地板价约束。

在低油价区间内：
汽油MAE为409.41元/吨；
柴油MAE为394.97元/吨。

这一误差显著高于正常油价区间。
原因在于，当国际油价低于40美元/桶时，机制层不再完全按照国际油价继续下跌进行传导。
理论调价信号被地板价截断，但实际调价仍可能受到前期累计、政策节奏和税费结构影响。

因此，低油价区间的主要特征是：
价格传递从连续传导转变为制度性截断，模型误差明显上升。


4. 正常油价区间分析

正常油价区间共有197个调价窗口，是样本的主体。
该区间平均油价为70.73美元/桶。

在正常油价区间内：
汽油MAE为61.88元/吨，方向准确率为94.42%；
柴油MAE为62.59元/吨，方向准确率为93.91%。

这说明在40美元/桶至130美元/桶之间，现行机制能够较稳定地将国际油价信号传递到国内成品油价格。
第九版模型在该区间内的误差较低，方向判断准确率较高，说明正常区间是机制运行最稳定的区间。

结合1.2的NARDL结果，在正常油价区间内，价格传递总体不存在显著的长期非对称性。
因此，正常区间内机制的主要特征可以概括为：
市场联动较充分，长期传导较稳定，政策平滑主要影响调价幅度而非调价方向。


5. 高油价区间分析

样本期内没有出现 MA_t >= 130 美元/桶的高油价区间，因此无法对天花板价机制进行直接实证估计。

这意味着队友原文档中关于高油价区间虚拟变量及其交互项的设定，在本样本中无法稳定估计。
如果强行加入高油价虚拟变量，该变量全为0，会导致模型无法识别其系数。

因此，本文只能从机制设计角度进行定性说明：
当国际油价超过130美元/桶时，国内成品油价格原则上不再继续上调或少调，天花板价机制会抑制极端高油价向国内价格的完全传导。


6. 关于区间NARDL交互项的说明

队友原文档中提出将低油价、高油价、正常油价虚拟变量与长期非对称参数相乘，以考察不同区间的不对称程度。
这一思路在理论上是合理的，但在当前样本中存在数据限制：

（1）低油价区间只有3个窗口，样本量过少，难以稳定估计交互项系数；
（2）高油价区间没有样本，虚拟变量恒为0，无法估计高油价交互项；
（3）正常油价区间占绝大多数，因此可主要依靠正常区间结果进行判断。

因此，本文在1.3中不强行报告区间交互NARDL系数，而采用分区统计结果和机制解释相结合的方式。
这样既保留了原文档的区间分析思路，也避免了因样本不足导致的虚假显著性。


7. 1.3 结论

严格按照低油价、正常油价、高油价三个制度区间分析后，可以得到以下结论：

（1）正常油价区间是样本主体，模型表现稳定。
在40-130美元/桶区间内，汽油和柴油方向准确率分别达到94.42%和93.91%，MAE约为62元/吨。

（2）低油价地板价区间误差显著增大。
低油价区间汽油和柴油MAE分别达到409.41元/吨和394.97元/吨，说明地板价机制明显改变了价格传递方式。

（3）高油价天花板区间没有样本，无法直接实证检验。
样本期最高窗口油价为123.52美元/桶，未达到130美元/桶，因此天花板价机制只能进行定性分析。

（4）综合来看，现行机制在正常区间内具有较稳定的市场联动性；在低油价区间，地板价约束会导致价格传递出现明显非线性；高油价天花板机制由于样本缺失暂不能验证。


三、可以写入论文的简洁结论
------------------------------------------------------------

基于第九版双因子状态空间模型提取的综合国际油价，本文按照NARDL方法对成品油价格传递不对称性进行检验。
结果显示，汽油和柴油的短期非对称性检验p值分别为0.3461和0.2724，长期非对称性检验p值分别为0.1103和0.1341，均未达到常用显著性水平。
因此，本文没有充分证据表明样本期内我国成品油价格存在稳定的短期或长期涨跌非对称传导。

进一步按照40美元地板价和130美元天花板价划分油价区间。
结果显示，正常油价区间内模型表现稳定，汽油和柴油方向准确率分别为94.42%和93.91%，MAE约为62元/吨；
低油价地板价区间误差显著增大，说明地板价约束会改变国际油价下跌向国内价格的传导方式；
样本期内未出现130美元以上的天花板区间，因此无法对天花板价机制进行直接实证检验。

由此可见，现行成品油定价机制在正常油价区间内具有较好的成本传导稳定性，而机制偏离主要出现在地板价等特殊制度区间。
