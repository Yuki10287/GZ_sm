第九版模型中的政策传导层不对称检验思路说明
============================================================

一、这版检验到底在检验什么
------------------------------------------------------------

这一版不是严格意义上的 NARDL 短期/长期非对称检验。

队友原始文档中的 NARDL 检验关注的是：
国际油价上涨/下跌是否会对国内成品油价格产生不同的短期影响和长期影响。
也就是说，它检验的是：

国际油价 -> 国内成品油价格

这一版我之前做出的“显著不对称”检验，关注的是另一个更贴合第九版模型的问题：

机制理论调价幅度 -> 实际公布调价幅度

也就是说，它检验的是：

如果按照现行定价机制，理论上应该调多少；
但实际发改委公布时，是否对“理论上调”和“理论下调”进行了不同程度的政策平滑。

因此，这一版更准确的名称应为：

“政策传导层不对称检验”

或者：

“理论调价信号向实际调价幅度传导的不对称检验”

它不是用来证明国际油价本身存在长期不对称传导，而是用来说明：
现行机制在执行层面会不会对上涨信号和下跌信号采取不同的调节力度。


二、为什么第九版模型适合做这个检验
------------------------------------------------------------

第九版最终模型由三层构成：

第一层：双因子状态空间模型
从 Brent、WTI、Dubai 三种国际原油价格中提取基础油价状态 X_t 和便利收益 delta_t。

第二层：机制理论调价层
按照现行调价规则计算理论调价幅度，包括：
1. 10个工作日移动平均；
2. 上一调价周期作为比较基准；
3. 1天计价滞后；
4. 50元/吨调价门槛；
5. 40美元地板价和130美元天花板价；
6. 美元兑人民币汇率折算。

这一层得到的变量是：
gasoline_theory_delta：汽油理论调价幅度；
diesel_theory_delta：柴油理论调价幅度。

第三层：RidgeCV 政策传导层
使用理论调价幅度、便利收益、汇率变化和期货期限结构，拟合实际公布调价幅度。

这一层的意义是：
即使理论机制给出一个调价金额，实际调价也可能受到政策平滑、地缘风险、汇率变化和市场预期影响。
因此，第九版模型不是只看“国际油价变了多少”，而是先计算“理论上应该调多少”，再研究“实际执行时调整了多少”。

正因为第九版模型已经明确区分了“机制理论值”和“实际公布值”，所以可以进一步检验：
理论上涨信号和理论下跌信号在政策执行层面是否被同等传导。


三、变量如何构造
------------------------------------------------------------

设第 t 个调价窗口中：

M_t 表示机制层计算得到的理论调价幅度；
A_t 表示实际公布调价幅度。

对于汽油：
M_t = gasoline_theory_delta
A_t = gasoline_actual_delta

对于柴油：
M_t = diesel_theory_delta
A_t = diesel_actual_delta

为了检验上涨和下跌传导差异，将理论调价幅度拆分为两个变量：

M_t^+ = max(M_t, 0)
M_t^- = min(M_t, 0)

其中：
M_t^+ 表示理论上应该上调的部分；
M_t^- 表示理论上应该下调的部分。

如果实际调价对上涨和下跌完全对称，那么 M_t^+ 和 M_t^- 的回归系数应该相同。
如果二者显著不同，则说明政策执行层面对上涨信号和下跌信号的传导力度不同。


四、回归模型设定
------------------------------------------------------------

使用如下传导方程：

A_t = α + ρA_{t-1} + β^+M_t^+ + β^-M_t^-
      + γ_1 delta_t + γ_2 Δe_t + γ_3 C_t + ε_t

其中：

A_t：实际调价幅度；
A_{t-1}：上一期实际调价幅度，用来控制调价惯性；
M_t^+：理论上调幅度；
M_t^-：理论下调幅度；
delta_t：双因子状态空间模型估计得到的便利收益或地缘溢价；
Δe_t：美元兑人民币汇率变化率；
C_t：Brent、Dubai、WTI 三种原油 M1/M3/M6 期货期限结构变量；
ε_t：误差项。

其中，C_t 包括：
term_spread_m1_m6_mean；
term_spread_m1_m3_mean；
term_spread_m3_m6_mean；
term_spread_m1_m6_change。

这几个变量共同反映期货市场对未来原油供需和价格压力的预期。


五、假设检验
------------------------------------------------------------

原假设：
H_0: β^+ = β^-

含义：
理论上调信号和理论下调信号向实际调价的传导力度相同，即政策传导对称。

备择假设：
H_1: β^+ ≠ β^-

含义：
理论上调信号和理论下调信号向实际调价的传导力度不同，即政策传导不对称。

本文使用 Wald 检验判断 β^+ 与 β^- 是否存在显著差异。
同时使用异方差稳健标准误，以降低不同调价窗口波动幅度不同带来的影响。


六、检验结果
------------------------------------------------------------

1. 全样本结果

样本    品种    样本数    上涨传导系数β+    下跌传导系数β-    Wald检验p值    R²
全样本  汽油    199       0.621             0.911             0.0103        0.845
全样本  柴油    199       0.711             1.029             0.0139        0.826

结果解释：
汽油和柴油的 Wald 检验 p 值均小于0.05。
因此，在5%显著性水平下，拒绝“政策传导对称”的原假设。
这说明理论上调信号和理论下调信号在实际调价执行中存在显著差异。


2. 正常油价区间结果

为了排除低油价地板价窗口对结果的影响，进一步只保留正常油价区间进行检验。

样本      品种    样本数    上涨传导系数β+    下跌传导系数β-    Wald检验p值    R²
正常区间  汽油    196       0.602             0.983             3.77e-07      0.915
正常区间  柴油    196       0.691             1.106             3.48e-06      0.892

结果解释：
在剔除低油价地板价窗口后，汽油和柴油的 p 值仍远小于0.01。
这说明政策传导不对称并不是完全由低油价地板价区间造成的，在正常油价区间内也依然存在。


3. 简单传导比率

为了更直观说明实际调价相对于理论调价的释放程度，计算实际调价总额与理论调价总额的比值。

品种    上涨窗口实际/理论传导比率    下跌窗口实际/理论传导比率
汽油    82.24%                     92.95%
柴油    94.31%                     106.15%

结果解释：
汽油上涨窗口中，实际调价总额约为理论调价总额的82.24%；
汽油下跌窗口中，实际调价总额约为理论调价总额的92.95%。

柴油上涨窗口中，实际调价总额约为理论调价总额的94.31%；
柴油下跌窗口中，实际调价总额约为理论调价总额的106.15%。

因此，样本期内下跌信号的释放程度高于上涨信号。


七、为什么这个检验会显著，而 NARDL 不显著
------------------------------------------------------------

这两个检验的对象不同。

1. NARDL 检验的是：
国际油价变化 -> 国内价格水平

它关注的是国际油价上涨和下跌，对国内汽油、柴油价格水平是否具有不同的短期和长期影响。

2. 政策传导层检验的是：
机制理论调价幅度 -> 实际公布调价幅度

它关注的是：
在现行机制已经计算出理论调价金额后，实际执行是否对上涨和下跌进行了不同程度的平滑。

因此，二者可能出现不同结论：

NARDL 不显著说明：
从国际油价到国内价格的长期成本传导看，涨跌差异没有达到统计显著水平。

政策传导层显著说明：
在具体调价执行层面，理论上调和理论下调并不是等比例传导到实际公布价格中。

这并不矛盾。
因为前者是长期价格关系检验，后者是制度执行层面的调价幅度检验。


八、经济含义
------------------------------------------------------------

根据检验结果，样本期内政策传导不对称主要表现为：

1. 上涨信号被一定程度平滑。
汽油上涨传导系数为0.621，柴油上涨传导系数为0.711，均小于1。
说明理论上调幅度并没有完全传导到实际调价中。

2. 下跌信号释放相对更充分。
汽油下跌传导系数为0.911，柴油下跌传导系数为1.029，均高于对应上涨系数。
说明实际机制对下调信号的传导程度高于上调信号。

3. 汽油政策平滑更明显。
汽油上涨传导比率为82.24%，柴油上涨传导比率为94.31%。
说明汽油价格在上涨阶段受到更强的平滑处理。

4. 柴油对理论机制信号更敏感。
柴油的上涨和下跌传导系数均高于汽油，说明柴油调价更接近理论调价信号。
这可能与柴油在运输、物流和工业生产中的成本属性有关。


九、论文中应如何表述
------------------------------------------------------------

建议不要把这部分表述为：
“NARDL 检验证明我国成品油价格存在显著长期非对称。”

因为严格 NARDL 检验并不支持这个结论。

更准确的表述是：

“为进一步考察现行机制在实际执行中的政策平滑特征，本文在双因子状态空间模型和机制理论调价层的基础上，构造政策传导层不对称检验。结果表明，理论上调幅度与理论下调幅度向实际调价幅度的传导系数存在显著差异，说明现行机制在执行层面存在政策传导不对称。该不对称主要表现为上涨信号受到一定平滑，而下跌信号释放相对更充分。”

如果需要和队友原文档中的 NARDL 部分衔接，可以这样写：

“NARDL 检验主要用于考察国际油价与国内成品油价格之间的长期传导关系。进一步地，考虑到我国成品油价格调整具有明确的行政调价窗口和机制约束，本文将研究对象从价格水平关系推进到调价幅度执行关系，检验机制理论调价信号向实际公布调价幅度的传导是否对称。”


十、这一版的最终结论
------------------------------------------------------------

第九版政策传导层不对称检验表明：

1. 理论调价信号向实际调价幅度的传导存在显著不对称；

2. 这种不对称在全样本和正常油价区间内均显著；

3. 不对称方向不是简单的“涨快跌慢”，而是“上涨平滑、下跌释放更充分”；

4. 这一结论反映的是政策执行层面的调价幅度差异，而不是 NARDL 意义上的国际油价长期传导非对称；

5. 因此，本文可以将其作为第九版模型对现行机制执行特征的进一步解释，而不应与严格 NARDL 检验混为一谈。
