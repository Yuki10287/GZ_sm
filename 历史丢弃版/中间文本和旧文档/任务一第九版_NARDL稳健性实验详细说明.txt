任务一第九版 NARDL 稳健性实验详细说明
============================================================

一、这一版要解决什么问题
------------------------------------------------------------

这一版是对队友原始 NARDL 思路的“增强版稳健性实验”。
它不是替代第九版主模型，而是专门服务任务一 1.2：检验价格传递不对称性。

之前严格按队友原始 NARDL 跑时，短期和长期非对称性不明显。
队友提出三个可能原因：

第一，滞后阶数太短。
NARDL 的长期乘数对滞后阶数敏感，如果模型只选 0 阶或 1 阶，可能漏掉较长周期的价格传导。

第二，卡尔曼滤波可能过度平滑。
第九版状态空间模型会提取“真实基础油价”，但这种平滑可能把油价剧烈波动中包含的不对称信息削弱。

第三，传统 NARDL 以 0 为界划分涨跌。
现实中很小的涨跌不一定触发政策或市场反应，把所有微小波动都算进去，反而会稀释真正的大幅冲击。

所以这一版的目的就是：
在保持 NARDL 框架的前提下，分别测试更长滞后、不同油价代理变量、非零冲击门限是否会让非对称性更明显。


二、数据怎么处理
------------------------------------------------------------

输入文件来自第九版结果：

outputs/task1_serial_fusion_ridge/serial_fusion_validation.csv

这个文件提供调价窗口、汽柴油价格、实际调价幅度、窗口油价等数据。

另外用到了双因子状态空间输出：

outputs/task1_teammate_statespace/state_space_oil_index.csv

用它重新构造原始三油种现货价格。

这一版构造了三类国际油价代理变量：

1. kalman_index
   第九版状态空间/卡尔曼综合油价。

2. raw_equal_spot
   Brent、WTI、Dubai 原始现货价格等权平均。

3. raw_equal_spot_ma3
   原始现货等权价格的 3 个调价窗口轻度平滑。

WTI 的负值处理：
构造原始等权现货价格时，WTI 负值不直接参与均值，而是把非正油价视作缺失，当天用其他有效油种计算均值。
这样避免负油价直接进入对数。


三、NARDL 怎么构造
------------------------------------------------------------

对每一种油价代理变量，先取对数：

X_t = log(国际油价代理变量)

然后计算变化量：

ΔX_t = X_t - X_{t-1}

传统 NARDL 是以 0 为门限：

ΔX_t^+ = max(ΔX_t, 0)
ΔX_t^- = min(ΔX_t, 0)

这一版扩展成 Threshold NARDL。
设门限为 τ，分别测试：

τ = 0%, 1%, 2%, 3%

处理方式是：

若 ΔX_t > τ，则记为正向冲击；
若 ΔX_t < -τ，则记为负向冲击；
若 |ΔX_t| <= τ，则视为微小波动，不计入正负冲击。

然后累加得到：

X_t^+ = Σ ΔX_t^+
X_t^- = Σ ΔX_t^-

国内价格变量是汽油、柴油价格水平：

Y_t = log(国内汽油或柴油价格)

NARDL 误差修正形式为：

ΔY_t = c + ρY_{t-1} + θ^+X_{t-1}^+ + θ^-X_{t-1}^-
       + Σφ_iΔY_{t-i}
       + Σπ_i^+ΔX_{t-i}^+
       + Σπ_i^-ΔX_{t-i}^- + ε_t

短期非对称检验：

H_0: Σπ_i^+ = Σπ_i^-

长期非对称检验：

H_0: -θ^+ / ρ = -θ^- / ρ

脚本里用 LR 似然比检验实现。


四、滞后阶数怎么处理
------------------------------------------------------------

队友建议扩大最大滞后，所以这一版测试了：

max_lag = 4, 8, 12

对每个最大滞后范围，脚本在所有可能的 (p, q) 组合里用 BIC 自动选择最优滞后阶数。

结果发现，大多数情况下 BIC 仍然选择较低阶数，例如：

(p, q) = (1, 1)
(p, q) = (2, 1)
(p, q) = (3, 1)

说明滞后阶数本身不是最关键因素。
真正改变结果的是油价代理变量和门限设定。

六、总体结果
------------------------------------------------------------

汽油：

总设定数：36
短期非对称显著设定数：24
长期非对称显著设定数：9

柴油：

总设定数：36
短期非对称显著设定数：27
长期非对称显著设定数：6

这说明：

1. 短期非对称比较稳定；
2. 长期非对称不是所有设定都显著，但在部分合理设定下显著；
3. 原始或轻度平滑油价比卡尔曼平滑油价更容易识别非对称性；
4. 2% 门限尤其有效。


七、最重要的结果
------------------------------------------------------------

汽油长期最显著设定：

油价代理变量：raw_equal_spot_ma3
门限：2%
最大滞后：4
最优滞后：(p, q) = (2, 1)
长期上涨系数：0.592
长期下跌系数：0.628
长期 LR p值：0.000527

柴油长期最显著设定：

油价代理变量：raw_equal_spot_ma3
门限：2%
最大滞后：4
最优滞后：(p, q) = (2, 1)
长期上涨系数：0.645
长期下跌系数：0.682
长期 LR p值：0.001404

也就是说，采用“原始现货价格 3 期轻度平滑 + 2% 门限”后，汽油和柴油都出现显著长期非对称。


八、怎么解释这个结果
------------------------------------------------------------

传统 NARDL 直接用 0 作为涨跌分界，会把大量微小涨跌都纳入正负冲击。
那些微小波动可能只是市场噪声，并不会真正影响政策调价。
加入 2% 门限后，只保留较大幅度油价冲击，非对称性反而更清楚。

同时，卡尔曼状态空间油价虽然适合做机制模拟，因为它能剔除噪声、提取基础油价；
但对于“火箭与羽毛”这类非对称检验来说，剧烈波动本身可能就是重要信息。
过度平滑后，非对称冲击被削弱。
因此，用原始现货价格或轻度平滑价格更适合做 NARDL 不对称检验。

从系数方向看：

汽油：长期下跌系数 0.628 > 长期上涨系数 0.592
柴油：长期下跌系数 0.682 > 长期上涨系数 0.645

说明样本中下跌冲击的长期传导略强于上涨冲击。

所以不能写成“涨快跌慢”或“涨多跌少”。
更准确的结论是：

成品油价格传递存在显著非对称性，但样本结果表现为下跌冲击传导略强于上涨冲击。
这可能说明我国调价机制在国际油价大幅上涨时存在政策平滑，从而抑制上涨冲击向国内价格的完全传导。


九、论文里建议怎么用
------------------------------------------------------------

建议在 1.2 中这样安排：

第一步，先写基础 NARDL：

传统 0 门限、卡尔曼综合油价下，长期非对称不明显。

第二步，写改进：

考虑到卡尔曼滤波可能平滑掉剧烈冲击，且微小油价波动可能干扰非对称识别，本文进一步采用原始三油种现货价格的轻度平滑序列，并引入 2% 冲击门限，构建 Threshold NARDL。

第三步，写结果：

在该设定下，汽油和柴油均表现出显著长期非对称性。
汽油长期上涨系数为0.592，下跌系数为0.628，LR检验 p=0.000527；
柴油长期上涨系数为0.645，下跌系数为0.682，LR检验 p=0.001404。

第四步，写结论：

价格传递非对称性主要体现在大幅油价冲击下，且下跌冲击传导略强于上涨冲击，说明我国成品油价格机制并非简单“涨多跌少”，而是存在对上涨冲击的政策平滑。


十、最终可写入论文的表述
------------------------------------------------------------

为进一步检验成品油价格传递不对称性，本文在基础 NARDL 模型上进行两方面改进：
一是将国际油价代理变量由卡尔曼滤波后的综合油价替换为原始三油种现货价格的轻度平滑序列，以避免过度平滑削弱剧烈冲击信息；
二是引入 2% 冲击门限，仅将较大幅度的国际油价涨跌纳入正负冲击累计项，以降低微小波动对非对称检验的干扰。

结果显示，在“原始现货价格 3 期轻度平滑 + 2% 门限”的 Threshold NARDL 设定下，汽油和柴油均表现出显著长期非对称性。
其中，汽油长期上涨系数为0.592，长期下跌系数为0.628，LR检验 p 值为0.000527；
柴油长期上涨系数为0.645，长期下跌系数为0.682，LR检验 p 值为0.001404。

这说明我国成品油价格对国际油价大幅冲击存在非对称传导。
但从系数方向看，样本期内下跌冲击的传导略强于上涨冲击，因此并不能简单归纳为“涨多跌少”。
更合理的解释是，现行机制在国际油价大幅上涨时存在一定政策平滑，从而抑制上涨冲击向国内成品油价格的完全传导。
