# 任务三主方案：累计压力缓冲账户下的分档比例调价规则

## 1. 主方案定位

任务三的核心目标不是重新求解一个比任务二更复杂的最优控制模型，而是将任务二滚动优化得到的复杂最优策略提炼为简洁、透明、可操作的政策规则。

结合题目要求和任务一、任务二已有结果，建议任务三主方案采用：

> 累计压力缓冲账户下的分档比例调价规则。

该规则把任务一得到的现行机制理论调幅视为“调价压力信号”，把任务二滚动优化策略中的分档释放、跨期缓冲和成本约束特征转化为可执行机制。

## 2. 为什么选择该方案

该方案适合作为任务三主模型，主要基于以下原因。

第一，它与现行机制兼容。

规则保留 10 个工作日调价窗口、50 元/吨调价门槛、40 美元地板价和 130 美元天花板价等制度基础，只是在现行机制上增加比例释放和跨期结转。

第二，它继承任务二最优策略的核心特征。

任务二滚动优化结果表明，最优策略并不是简单地每期完全执行理论调幅，而是在暂缓、部分释放和充分释放之间动态选择，并通过降低价格路径弯折程度显著减少预期平滑损失。因此，任务三规则必须保留“分档比例执行”和“跨期缓冲账户”。

第三，它比黑箱模型更透明。

决策树、随机森林或其他分类模型也可以拟合任务二最优动作，但它们不适合作为政策机制主体。题目要求的是简洁、透明、可操作的规则，而不是单纯预测最优动作。因此，主方案应采用分档表和少量修正条件表达。

## 3. 规则变量定义

第 t 个调价窗口，定义：

```text
Delta_t^M = 任务一第九版模型得到的现行机制理论调幅
B_{t-1} = 上一期未释放的调价压力
S_t = 第 t 期累计调价压力
A_t = 第 t 期最终执行调价额
r_t = 第 t 期执行比例
```

累计调价压力为：

```text
S_t = Delta_t^M + B_{t-1}
```

其中 `B_0 = 0`。

## 4. 基础分档比例规则

根据累计调价压力绝对值 `|S_t|` 确定基础执行比例 `r_t^0`。

| 累计调价压力区间 | 基础执行比例 |
|---|---:|
| `|S_t| < 50` | 0 |
| `50 <= |S_t| < theta_1` | 0.25 |
| `theta_1 <= |S_t| < theta_2` | 0.50 |
| `theta_2 <= |S_t| < theta_3` | 0.75 |
| `|S_t| >= theta_3` | 1.00 |

基础调价额为：

```text
A_t^0 = r_t^0 * S_t
```

这一分档设计的含义是：

- 小幅压力暂缓释放，避免频繁调价；
- 中等压力部分释放，平滑价格路径；
- 大幅压力提高释放比例，避免压力过度累积；
- 极端压力充分释放，防止国内价格长期偏离国际成本基础。

## 5. 成本安全修正

任务二结果显示，最优策略的总损失下降主要来自预期平滑损失下降，但消费者福利、企业利润保障和能源安全损失并非全部同步下降。因此，任务三规则不能只追求平滑，还需要显式考虑企业合理利润和供应安全。

当累计调价压力为负，即规则倾向下调时，如果国内价格接近库存成本和合理利润底线，则执行比例降低一档：

```text
if S_t < 0 and cost_margin_t < kappa:
    r_t = max(r_t^0 - 0.25, 0.25)
else:
    r_t = r_t^0
```

其中：

```text
cost_margin_t = 国内成品油价格相对成本和合理利润底线的安全边际
kappa = 成本安全阈值
```

这一修正体现“成本约束下的非对称调节”：

- 上调时保留必要成本传导；
- 下调时避免价格过快跌破库存成本和合理利润基础；
- 兼顾炼油企业利润保障和能源供应稳定。

## 6. 波动平滑修正

任务二五维损失分解表明，相比现行机制，最优策略的主要福利改进来自价格预期平滑损失的大幅下降。因此，任务三规则需要在国际油价高波动或调价方向频繁反转时主动降低执行强度。

设：

```text
volatility_t = 国际油价滚动波动率
nu = 高波动阈值
direction_reversal_t = 调价方向是否发生反转
```

如果出现高波动或方向反转，则执行比例降低一档：

```text
if volatility_t > nu or direction_reversal_t == 1:
    r_t = max(r_t - 0.25, 0)
```

这一修正的政策含义是：

- 在油价不确定性较强时，减少国内价格跟随国际油价的机械波动；
- 在连续调价方向反复变化时，降低价格路径弯折程度；
- 稳定消费者、企业和市场主体的价格预期。

## 7. 最终调价额和结转账户

经过成本安全修正和波动平滑修正后，最终调价额为：

```text
A_t = r_t * S_t
```

未释放的调价压力进入下一期：

```text
B_t = S_t - A_t
```

如果最终调价额低于 50 元/吨门槛，则本期不实际调价，压力全部结转：

```text
if |A_t| < 50:
    A_t = 0
    B_t = S_t
```

结转账户是本规则的核心。它保证未释放的国际油价压力不会被忽略，而是进入后续窗口，在更合适的时点逐步释放。

## 8. 参数确定方法

规则参数包括：

```text
Theta = (theta_1, theta_2, theta_3, kappa, nu)
```

参数不宜主观指定，也不宜使用过度复杂的连续优化。建议采用小规模可解释网格搜索。

候选阈值可以设置为若干整数档，例如：

```text
theta_1 in {100, 150, 200}
theta_2 in {250, 300, 350}
theta_3 in {450, 500, 600}
```

对每一组参数，生成简化规则调价路径，并代入任务二相同的五维社会福利损失函数：

```text
L_t = w_c * consumer_loss_t
    + w_p * profit_loss_t
    + w_i * cpi_loss_t
    + w_e * expectation_loss_t
    + w_s * security_loss_t
```

选择使样本期总损失最小的参数：

```text
min_Theta sum_t L_t(A_t(Theta))
```

如果多个参数组合的损失接近，则优先选择更简单、更容易解释、更接近政策口径的整数阈值。

## 9. 与任务一、任务二的衔接

该规则与前两问的关系如下。

任务一提供调价压力信号：

```text
Delta_t^M
```

即基于双因子状态空间、修正调价机制层和 RidgeCV 政策传导层得到的理论机制调幅。

任务二提供规则提取依据：

```text
ratio_t in {0, 0.25, 0.5, 0.75, 1.0}
```

即滚动优化策略中“理论调幅比例执行”的思想，以及五维社会福利损失函数。

任务三将二者转化为可执行机制：

```text
累计压力信号 -> 分档比例执行 -> 未释放压力结转 -> 成本和波动修正
```

## 10. 后续检验思路

规则确定后，应从两个层面检验。

第一，样本期内比较：

- 现行机制；
- 任务二滚动优化最优策略；
- 任务三简化规则。

重点比较：

- 平均总福利损失；
- 五维损失分解；
- 平均绝对调幅；
- 大幅调价次数；
- 调价方向稳定性；
- 规则保留任务二福利改进的比例。

第二，国际油价不确定性下的鲁棒性检验：

- 基准波动情景；
- 高波动情景；
- 单边上涨冲击；
- 单边下跌冲击；
- 先涨后跌反转情景；
- 极端油价冲击情景。

核心判断是：

```text
loss_optimal < loss_rule < loss_current
```

并检验简化规则是否在多数情景下保持更低福利损失、更少大幅调价和更平滑价格路径。

## 11. 可用于论文的概括表述

本文在任务二滚动优化策略基础上，提取出一种累计压力缓冲账户下的分档比例调价规则。该规则以现行机制理论调幅为调价压力信号，根据累计压力大小在 0、25%、50%、75% 和 100% 五档执行比例之间选择，并将未释放压力跨期结转。同时，当价格接近成本和合理利润底线时降低下调比例，当国际油价处于高波动或调价方向频繁反转时降低执行比例。规则参数由任务二社会福利损失函数在可解释参数空间内反推确定。该规则既保留现行机制的基本制度框架，又吸收滚动优化策略中的平滑和缓冲特征，能够作为复杂最优动态策略的简洁政策表达。
