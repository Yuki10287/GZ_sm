## 1. 总体建模主线

本题分三问，最终形成如下主线：

1. 任务一：还原并验证现行成品油定价机制，分析价格传导和区间差异；
2. 任务二：将调价看作动态决策问题，构建五维社会福利损失函数，用有限期滚动优化求解较优动态调价策略；
3. 任务三：不再构建复杂新模型，而是从任务二最优策略中提取一套公众可理解、部门可执行的简化规则，并检验其在国际油价随机扰动下的稳定性，最后提出政策建议。

## 2. 任务一：现行机制理解与验证

### 2.1 最终模型

任务一最终采用第九版模型：

> 双因子状态空间 + 修正调价机制层 + RidgeCV 政策传导层。

框架如下：

1. 双因子状态空间模型从 Brent、WTI、Dubai 中提取基础油价状态 `X_t` 和便利收益/地缘溢价 `delta_t`；
2. 修正调价机制层模拟现行机制，包括 10 个工作日窗口、上一周期均价基准、1 天计价滞后、50 元/吨门槛、40 美元地板价和 130 美元天花板价；
3. RidgeCV 政策传导层使用理论调幅、`delta_t`、汇率变化和 M1/M3/M6 期货期限结构拟合实际调价幅度。

## 3. 任务二：动态调价优化

### 3.1 最终模型

任务二最终采用：

> 五维社会福利损失函数 + 有限期滚动优化。

没有采用严格值迭代 MDP 作为论文主模型。

五维损失包括：

1. 消费者福利损失；
2. 炼油企业合理利润保障损失；
3. CPI 通胀损失；
4. 价格预期平滑损失；
5. 能源安全与供应稳定性损失。

滚动优化设定：

```text
预测期 H = 3 个调价窗口
ratio_grid = [0, 0.25, 0.5, 0.75, 1.0]
optimal_delta = ratio * current_mechanism_delta
```

保留 50 元/吨调价门槛，并允许未释放压力跨期结转。

### 3.4 任务二策略特征

任务二最优策略总结为三大核心特征：

1. 分档释放特征：理论调幅不是必须全额执行的指令，而是压力信号；
2. 跨期缓冲特征：未完全释放的调价压力通过结转项进入后续窗口；
3. 成本约束下的非对称调节特征：上调保留必要成本传导，下调更谨慎。

## 4. 任务三：规则提取、鲁棒性检验与政策建议

### 4.1 任务三定位

任务三不再构建新的复杂优化模型，而是将任务二复杂滚动优化策略转化为一套简洁、透明、可执行的规则。

最终规则：

> 调价压力缓冲账户下的分档比例释放规则。

核心表述：

```text
先算应调幅度，再分档释放；
没调完的部分进入账户；
油价波动大时慢调，成本压力大时慎降。
```

### 4.2 简化规则内容

规则流程：

1. 每 10 个工作日计算本期可释放压力；
2. 本期可释放压力 = 本期新增理论调幅 + 上期压力账户余额；
3. 若低于 50 元/吨门槛，则不调价，压力继续入账；
4. 若超过门槛，则按压力大小执行 25%、50%、75% 或 100%；
5. 若本期为下调且接近成本和合理利润底线，则执行比例降低一档；
6. 若国际油价高波动或调价方向频繁反转，则执行比例降低一档；
7. 未释放压力继续进入下一期账户。

该规则对应任务二三大特征：

- 分档释放；
- 跨期缓冲；
- 成本约束下的非对称调节。

### 4.4 鲁棒性检验最终版本

最终采用队友认可的简化口径：

> 不分很多情景，也不主要和现行机制对比，而是考察同一条简化规则在加入高斯扰动后，效果相对无扰动基准是否变化很大。

扰动方式：

```text
ln P_t^sim = ln P_t + epsilon_t
epsilon_t ~ N(0, sigma_noise^2)
sigma_noise = 0.1 * sigma_historical
```

说明：

- 扰动加在国际油价水平对数上；
- 不加在收益率上，避免噪声逐期累积成新趋势；
- 每个油品模拟 500 次；
- 比较扰动前后同一简化规则的效果变化。

### 4.5 鲁棒性检验结果

核心结果：

| 指标 | 总体结果 |
|---|---:|
| 平均福利损失变化 | +4.30% |
| 平均调价幅度变化 | +0.89% |
| 预期平滑损失变化 | +8.19% |
| 损失变化在 ±10% 内路径占比 | 93.90% |
| 压力账户余额变化 | +1.61% |

结论：

> 加入中等强度高斯扰动后，简化规则的主要效果没有发生明显变化，说明规则对国际油价随机波动具有一定鲁棒性。

## 8. 最终论文主结论建议

可以将全题主结论概括为：

> 现行成品油价格机制具有较强可解释性，但在价格路径平滑和跨期调节方面仍有改进空间。基于五维社会福利损失函数的滚动优化结果表明，分档释放、跨期缓冲和成本约束下的非对称调节可以显著降低总福利损失，尤其是价格预期平滑损失。进一步将复杂动态策略提炼为“调价压力账户 + 分档比例释放 + 高波动降档 + 成本安全约束”的简化规则后，该规则在国际油价高斯扰动下主要效果保持稳定，适合作为现行成品油价格调控机制的可执行改进方案。
