# 任务二滚动优化主模型整理说明

## 一、模型定位

本版任务二采用“社会福利损失函数 + 有限期滚动优化”的动态调价模型。模型没有推翻队友《任务二(1).docx》中提出的五维社会福利损失框架，而是在其基础上进行可计算化和政策可执行化处理。

本文将每一次成品油调价窗口视为一个动态决策节点。给定任务一得到的理论机制调幅，政府不再被动执行全部理论调幅，而是在若干比例执行方案中选择未来若干期贴现社会福利损失最小的调价幅度。

模型的核心思想为：

```text
任务一理论调幅 -> 比例执行策略 -> 未来H期福利损失评估 -> 只执行当前期动作 -> 下一期重新优化
```

基准设定中滚动预测期取 `H=3`，折现因子取 `beta=0.98`。

## 二、社会总福利损失函数

保留队友文档中的五维社会福利损失结构：

```text
L_t = w_cs L_cs,t + w_profit L_profit,t + w_cpi L_cpi,t
    + w_exp L_exp,t + w_sec L_sec,t
```

五类损失分别为：

1. 消费者福利损失；
2. 炼油企业合理利润保障损失；
3. CPI通胀损失；
4. 价格预期平滑损失；
5. 能源安全与供应稳定性损失。

### 1. 消费者福利损失

消费者福利损失仍使用恒定弹性需求函数下的价格偏离无谓损失。需求价格弹性取 `epsilon=-0.6`。需求规模不再使用原油进口量代理，而是使用汽油、柴油表观消费量。

### 2. 炼油企业利润保障损失

利润损失采用合理利润率偏离的二次惩罚：

```text
L_profit = (margin_t - target_margin)^2
```

其中目标合理利润率 `target_margin=0.06`。由于缺少月度炼油毛利和WACC数据，模型使用进口原油成本构造库存成本，并以国内成品油价格与库存成本之间的利润空间近似炼油企业利润状态。

### 3. CPI通胀损失

CPI损失表示预测通胀率偏离政策目标的程度：

```text
L_cpi = (pi_t - pi*)^2
```

CPI转移方程加入本期和上一期调价率：

```text
pi_t = alpha0 + alpha1*pi_{t-1}
     + theta0*(a_t/P_{t-1})
     + theta1*(a_{t-1}/P_{t-2})
```

基准估计参数为：

```text
alpha0 = 0.000488
alpha1 = 0.951928
theta0 = 0.008268
theta1 = 0.025614
```

### 4. 预期平滑损失

预期平滑项惩罚价格路径的二阶差分：

```text
L_exp = ((P_t - 2P_{t-1} + P_{t-2}) / scale)^2
```

由于：

```text
P_t - 2P_{t-1} + P_{t-2} = a_t - a_{t-1}
```

代码中等价实现为：

```text
L_exp = ((a_t - a_{t-1}) / 500)^2
```

### 5. 能源安全损失

为避免原始指数型惩罚过强导致总损失被能源安全项完全支配，本版将能源安全损失改为分段二次惩罚：

```text
若 P_t >= inventory_cost*(1+target_margin)，能源安全损失为0；
若 inventory_cost <= P_t < inventory_cost*(1+target_margin)，利润不足但未倒挂，使用温和二次惩罚；
若 P_t < inventory_cost，价格倒挂，使用较强二次惩罚。
```

基准参数为：

```text
security_penalty_mild = 8
security_penalty_severe = 35
```

这样处理后，能源安全仍能约束价格长期低于成本，但不会像固定大额惩罚那样支配全部结果。

## 三、动态优化求解方法

本版不采用严格高维值迭代作为主模型，而采用有限期滚动优化。原因是连续状态空间下严格贝尔曼方程求解复杂，且部分状态变量缺乏直接观测数据。

每个调价窗口 `t`，模型枚举未来 `H=3` 期的执行比例组合：

```text
ratio_grid = [0, 0.25, 0.5, 0.75, 1.0]
```

动作定义为：

```text
a_t = ratio_t * mechanism_delta_t
```

若绝对调价幅度小于50元/吨，则本期不执行调价，并将未执行部分计入 `carry_over`。

每一期求解：

```text
min L_t + beta*L_{t+1} + beta^2*L_{t+2}
```

模型只执行最优动作序列中的第一个动作，下一调价窗口重新滚动优化。

## 四、与队友《任务二(1).docx》的差异

本版保留队友文档的五维福利损失函数和动态调价思想，但在以下方面做了调整：

1. **求解方式不同**

队友文档写的是马尔可夫决策过程和贝尔曼值迭代。本文主模型采用有限期滚动优化。严格MDP值迭代版已经作为对照模型另行实现，但由于其结果更偏理论最优控制，政策执行解释性弱于滚动优化模型。

2. **动作空间不同**

队友文档将控制变量定义为实际调价幅度。本版将动作约束为任务一理论机制调幅的执行比例：

```text
a_t = ratio * mechanism_delta_t
```

这样做可以保证任务二与任务一结果直接衔接，也避免出现脱离现行机制的大幅任意调价。

3. **能源安全损失不同**

队友文档采用指数型惩罚，以体现能源断供的高风险。本版改为分段二次惩罚。原因是指数惩罚在实际计算中容易使能源安全项过度主导总损失，导致优化结果过于极端。

4. **CPI方程增强**

队友文档中CPI主要由上一期通胀和本期油价变化驱动。本版加入上一期调价率，以刻画油价调整对CPI的滞后传导。

5. **需求量数据落地方式不同**

队友文档中的需求量是理论变量。本版使用实际整理的汽油、柴油表观消费量作为需求规模。

6. **权重设置更数据化**

消费者权重由交通通信支出占居民总消费支出的比例校准，而不是完全主观设定。其他权重仍保留政策偏好设定，并通过政策情景进行对比。

## 五、数据处理说明

### 1. 汽油、柴油表观消费量

表观消费量按以下公式计算：

```text
gasoline_apparent_consumption = gasoline_output + gasoline_import - gasoline_export
diesel_apparent_consumption = diesel_output + diesel_import - diesel_export
```

其中：

- 产量来自国家统计局汽油、柴油产量数据；
- 进口和出口来自海关统计平台；
- 海关数量原始单位为千克，统一换算为万吨；
- 月度缺失值使用线性插值；
- 序列两端缺失值使用最近有效值延伸。

最终表观消费量数据共125个月，无缺失值。描述统计如下：

```text
汽油表观消费量均值：1120.17 万吨/月
汽油表观消费量最小值：766.72 万吨/月
汽油表观消费量最大值：1331.68 万吨/月

柴油表观消费量均值：1443.62 万吨/月
柴油表观消费量最小值：957.42 万吨/月
柴油表观消费量最大值：1832.78 万吨/月
```

### 2. 居民消费支出数据

使用两组年度数据：

```text
全国居民人均交通通信消费支出
全国居民人均消费支出
```

计算：

```text
transport_share = 交通通信人均消费支出 / 全国居民人均消费支出
```

样本均值为：

```text
transport_share_mean = 0.1365
```

该比例用于校准消费者福利权重。

### 3. 原油进口成本与库存成本

由于缺少炼厂真实库存成本、库存周转天数和月度炼油毛利数据，本文使用进口原油每吨人民币成本构造库存成本：

```text
inventory_cost_t = 0.5*cost_t + 0.3*cost_{t-1} + 0.2*cost_{t-2} + refining_cost
```

其中 `refining_cost` 由历史国内成品油价格和进口原油成本校准，使中位利润率接近目标合理利润率。

### 4. 缺失数据处理

缺失产量、进口、出口数据使用线性插值。序列开头或结尾缺失时，用最近有效值延伸。

没有找到或不可公开获得的数据包括：

- 月度炼油毛利；
- 炼厂开工率；
- 商业库存；
- 炼厂WACC；
- 真实供需缺口。

这些变量分别使用进口原油成本、库存成本、目标利润率、表观消费量和分段安全惩罚进行近似。

## 六、政策情景设置

模型设置四类政策情景：

1. `baseline`：基准情景；
2. `livelihood_priority`：民生优先，提高消费者权重；
3. `stability_priority`：稳定预期优先，提高CPI与预期平滑权重；
4. `security_priority`：能源安全优先，提高能源安全和企业利润权重。

基准情景归一化权重为：

```text
consumer = 0.1298
profit = 0.0523
cpi = 0.2092
expectation = 0.1712
security = 0.4375
```

## 七、模型结果

### 1. 基准情景结果

| 品种 | 实际平均总损失 | 机制平均总损失 | 最优平均总损失 | 相对实际下降 | 相对机制下降 | 最优平均绝对调价 |
|---|---:|---:|---:|---:|---:|---:|
| 汽油 | 0.07745 | 0.06868 | 0.02783 | 64.07% | 59.48% | 117.93 元/吨 |
| 柴油 | 0.07573 | 0.06352 | 0.02715 | 64.14% | 57.25% | 113.70 元/吨 |

基准情景下，滚动优化策略相较实际调价和机制调价均显著降低综合社会福利损失。优化后的平均调价幅度低于实际调价和机制调价，说明模型并非通过更大幅度调价获得损失下降，而是通过跨期平滑和动态权衡改善价格路径。

### 2. 五类损失分解

汽油：

| 损失类别 | 实际 | 机制 | 滚动优化 |
|---|---:|---:|---:|
| 消费者福利 | 0.000721 | 0.000718 | 0.001006 |
| 企业利润 | 0.002165 | 0.002006 | 0.003036 |
| CPI通胀 | 0.000074 | 0.000074 | 0.000074 |
| 预期平滑 | 0.426557 | 0.385506 | 0.069591 |
| 能源安全 | 0.009619 | 0.005647 | 0.014056 |

柴油：

| 损失类别 | 实际 | 机制 | 滚动优化 |
|---|---:|---:|---:|
| 消费者福利 | 0.000842 | 0.000828 | 0.001141 |
| 企业利润 | 0.002530 | 0.002297 | 0.003408 |
| CPI通胀 | 0.000078 | 0.000078 | 0.000078 |
| 预期平滑 | 0.411700 | 0.353482 | 0.064588 |
| 能源安全 | 0.011427 | 0.006316 | 0.014881 |

结果表明，滚动优化策略的主要改善来源是显著降低预期平滑损失。消费者福利、企业利润和能源安全损失略有上升，说明该策略不是在所有单项指标上同时最优，而是在多目标权衡下获得较低的综合损失。

### 3. 政策情景结果

| 情景 | 品种 | 最优平均总损失 | 相对实际下降 | 相对机制下降 | 最优平均绝对调价 |
|---|---|---:|---:|---:|---:|
| baseline | 汽油 | 0.02783 | 64.07% | 59.48% | 117.93 |
| baseline | 柴油 | 0.02715 | 64.14% | 57.25% | 113.70 |
| livelihood_priority | 汽油 | 0.02682 | 65.06% | 60.72% | 117.77 |
| livelihood_priority | 柴油 | 0.02604 | 65.24% | 58.72% | 114.21 |
| stability_priority | 汽油 | 0.03123 | 72.24% | 69.01% | 115.78 |
| stability_priority | 柴油 | 0.02987 | 72.67% | 67.81% | 110.48 |
| security_priority | 汽油 | 0.02579 | 56.23% | 50.04% | 126.41 |
| security_priority | 柴油 | 0.02543 | 56.21% | 47.02% | 120.26 |

稳定优先情景下，最优平均绝对调价幅度最低，说明提高CPI与预期平滑权重会使模型倾向于更平缓的调价路径。能源安全优先情景下，最优调价幅度上升，符合保障供应稳定时需要更充分传导成本变化的政策直觉。

### 4. 其他评价指标

基准情景下：

```text
汽油大幅调价次数(abs(delta)>=500)：3次
柴油大幅调价次数(abs(delta)>=500)：3次

汽油与机制调价方向一致率：68.5%
柴油与机制调价方向一致率：69.0%

汽油与实际调价方向一致率：66.0%
柴油与实际调价方向一致率：67.5%

汽油平均carry_over绝对值：76.12 元/吨
柴油平均carry_over绝对值：74.86 元/吨
```

这些指标说明滚动优化策略仍大体遵循任务一机制调价方向，同时通过比例执行和跨期结转降低短期剧烈波动。

## 八、与严格MDP版和单期版的关系

为验证模型改进效果，另行构建了两类对照：

1. `docx_myopic_with_data`：五维损失 + 已整理数据 + 单期比例搜索；
2. `docx_strict_mdp_value_iteration`：按队友docx更严格实现的离散MDP和值迭代。

对照结果显示：

- 单期版能降低损失，但预期平滑损失较高；
- 严格MDP版数学优化更强，但动作更偏理论最优控制，方向一致率较低；
- 滚动优化版在损失下降、调价幅度、方向一致率和政策可解释性之间更均衡。

因此本文建议将滚动优化版作为任务二主模型，将严格MDP值迭代版作为理论动态规划对照，将单期版作为无跨期优化对照。

## 九、结论

本版滚动优化模型在保留队友五维社会福利损失框架的基础上，将任务一得到的理论机制调幅转化为可执行的动态比例调价策略。结果表明，相较现行实际调价和机制调价，滚动优化策略能够显著降低综合福利损失，尤其有效降低价格路径的预期冲击，同时保持调价幅度处于现实政策可解释范围。

需要注意的是，由于炼油毛利、库存、开工率和WACC等高频企业经营数据不可得，模型中利润和能源安全部分仍为基于公开数据的近似刻画。因此结果更适合作为政策模拟和机制优化方案，而不是对现行机制的绝对替代判断。
