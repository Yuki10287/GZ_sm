# 任务三第一部分：简化调价规则提取求解

## 1. 问题定位

任务二已经通过有限期滚动优化得到了一条较优的动态调价路径，但这条路径依赖社会福利损失函数、前瞻窗口、动作空间和跨期状态更新，直接作为政策规则时不够直观，也不便于向公众解释。

因此，任务三第一部分的目标不是重新建立新的复杂优化模型，而是回答：

> 如何把任务二中较复杂的动态调价策略，提炼成一套“什么时候调、调多少、什么时候缓一缓”的简单执行规则？

本文将任务二最优策略中的核心规律概括为：

> 国际油价变化先形成调价压力，国内成品油价格不机械一次性跟随，而是按压力大小分档释放；没有释放完的压力进入缓冲账户；遇到成本安全压力或国际油价剧烈波动时，调价比例降低一档。

由此得到任务三的简化规则：

> 调价压力缓冲账户下的分档比例释放规则。

## 2. 从任务二中提取出的核心规律

任务二最优策略显示，较优的调价方式并不是每期完全执行理论调幅，而是在不同状态下选择暂缓、部分执行或充分执行。其可解释规律主要有三条。

### 2.1 理论调幅是压力信号，不是必须全额执行的指令

任务一给出的理论机制调幅反映国际油价、汇率、便利收益和现行政策机制共同作用下的调价压力。

任务二的结果表明，这个压力不一定要在当期全部释放。压力较小时，可以暂缓；压力中等时，可以部分释放；压力较大时，再提高释放比例。

通俗地说：

> 该调多少是一回事，当期实际调多少是另一回事。政策可以根据压力大小分批释放，而不是机械全额跟随。

### 2.2 没有调完的部分不能消失，要记入缓冲账户

如果某一期没有把调价压力全部释放，剩余部分不应被忽略，而应进入下一期继续考虑。

这可以理解为建立一个“调价压力缓冲账户”。为避免重复累计，规则中区分三个概念：

- 本期新增调价压力：由任务一理论机制在本窗口给出的新增调幅；
- 上期压力账户余额：过去没有释放完、结转到本期的余额；
- 本期可释放压力：本期需要判断是否释放的总压力。

三者关系为：

```text
本期可释放压力 = 本期新增调价压力 + 上期压力账户余额
```

缓冲账户的作用是：

- 避免每次国际油价小幅变化都立即传导到国内价格；
- 避免长期压制价格信号；
- 在油价连续变化时逐步释放压力；
- 在油价反复震荡时减少国内价格大起大落。

### 2.3 高波动和成本安全压力下，需要降低调价强度

任务二的五维损失分解显示，最优策略相对于现行机制的主要改进来自价格预期平滑损失下降。这说明简化规则应特别重视价格路径平稳。

同时，任务二结果也显示，最优策略并不是让消费者福利、企业利润、CPI、预期稳定和能源安全五个维度全部同时改善，而是在多目标之间折中。

因此，简化规则需要保留两个容易解释的降档机制：

- 当国际油价高波动或调价方向频繁反转时，降低执行比例；
- 当本期应下调但价格接近成本和合理利润底线时，降低下调比例。

## 3. 简化调价规则

本文将任务三第一部分的规则提取结果概括为五步。

### 第一步：每 10 个工作日计算一次本期可释放压力

沿用现行机制的 10 个工作日调价窗口。每个窗口先计算本期可释放压力：

```text
本期可释放压力 = 本期新增理论调幅 + 上期压力账户余额
```

其中：

- 本期新增理论调幅来自任务一第九版模型得到的现行机制理论调幅；
- 上期压力账户余额来自上一期没有释放完的部分；
- 第一期开启时，压力账户余额为 0。

这一规则保留了现行机制的基本周期，又引入了任务二最优策略中的跨期缓冲思想。

### 第二步：按本期可释放压力大小分档释放

将本期可释放压力按大小分为五类，并设置相应执行比例。

| 本期可释放压力状态 | 执行规则 | 通俗解释 |
|---|---:|---|
| 不足 50 元/吨 | 不调价 | 压力太小，暂时不动 |
| 小幅压力 | 执行 25% | 少量释放，避免频繁跳动 |
| 中等压力 | 执行 50% | 稳步释放，兼顾传导和平滑 |
| 较大压力 | 执行 75% | 加快释放，防止压力积累过多 |
| 极大压力 | 执行 100% | 全部释放，避免价格严重偏离成本 |

这条规则可以概括为：

> 小幅不动，中幅慢调，大幅快调，极端全调。

其中 50 元/吨门槛沿用现行机制；其他分档阈值可以根据任务二最优策略中的动作分布进行归纳确定，论文中不需要把它表述成新的复杂优化问题。

### 第三步：本期应下调且成本压力较高时，降低一档

如果本期可释放压力为负，说明本期规则倾向于下调国内成品油价格。此时若国内价格已经接近库存成本和合理利润底线，则下调比例降低一档。

执行方式为：

| 原执行比例 | 成本安全压力较高时 |
|---:|---:|
| 100% | 降为 75% |
| 75% | 降为 50% |
| 50% | 降为 25% |
| 25% | 维持 25% 或暂缓 |

政策含义是：

> 油价下跌可以向消费者传导，但不宜一次性下调过快，以免挤压炼油企业合理利润并影响供应稳定。

这一规则对应任务二中的能源安全和企业利润保障约束。

### 第四步：国际油价剧烈波动或方向反复时，降低一档

如果近期国际油价波动明显加大，或者连续调价窗口中出现“上调后又下调”“下调后又上调”的频繁反转，则本期执行比例降低一档。

执行方式为：

| 原执行比例 | 高波动或方向反转时 |
|---:|---:|
| 100% | 降为 75% |
| 75% | 降为 50% |
| 50% | 降为 25% |
| 25% | 降为 0 或维持 25% |

政策含义是：

> 当外部油价仍在剧烈摇摆时，国内价格不急于完全跟随，先稳一稳，减少公众和企业预期的大幅波动。

这一规则对应任务二中价格预期平滑损失的明显改善。

### 第五步：未释放压力继续记账

本期实际调价后，尚未释放的压力进入下一期缓冲账户。

```text
下期压力账户余额 = 本期可释放压力 - 本期实际调价额
```

如果本期计算出的实际调价额仍不足 50 元/吨，则本期不实际调价，压力全部进入下一期。

```text
若本期实际调价额不足 50 元/吨：
    本期调价额 = 0
    本期可释放压力全部进入压力账户
```

这一步保证：

> 暂缓不是取消，少调不是不调；没有释放的压力会被记录，并在后续窗口继续处理。

## 4. 最终可执行规则汇总

任务三提取出的简化规则可以写成如下执行流程。

1. 每 10 个工作日，计算一次本期可释放压力。
2. 若可释放压力不足 50 元/吨，则不调价，压力进入缓冲账户。
3. 若可释放压力超过 50 元/吨，则按压力大小选择 25%、50%、75% 或 100% 的执行比例。
4. 若本期为下调且成本安全压力较高，则执行比例降低一档。
5. 若国际油价高波动或调价方向频繁反转，则执行比例降低一档。
6. 执行调价后，未释放压力进入下一期缓冲账户。

可概括为：

```text
先记账，再分档；该调则调，未调结转；高波动慢调，成本紧时慎降。
```

## 5. 与现行机制的区别

该规则不是推翻现行机制，而是在现行机制基础上增加缓冲和分档。

| 比较维度 | 现行机制 | 简化规则 |
|---|---|---|
| 调价周期 | 10 个工作日 | 保留 10 个工作日 |
| 调价门槛 | 50 元/吨 | 保留 50 元/吨 |
| 理论调幅处理 | 达到门槛后倾向一次性释放 | 作为压力信号分档释放 |
| 未释放压力 | 机制中缺少显式账户 | 进入缓冲账户跨期处理 |
| 高波动时期 | 主要依靠临时政策判断 | 明确降低执行比例 |
| 成本安全约束 | 特殊情形下调整 | 下调时设置降档规则 |
| 公众解释 | 规则存在但调幅变化不够平滑 | 可解释为“压力分批释放” |

## 6. 与任务二最优策略的关系

任务三简化规则不是新的最优策略，也不声称优于任务二滚动优化策略。

二者关系是：

- 任务二提供理论上的复杂最优调价路径；
- 任务三从该路径中提取公众可理解的稳定规律；
- 简化规则牺牲一部分精细度，换取透明性、稳定性和执行便利。

因此，论文中应表述为：

> 简化规则是任务二复杂动态策略的政策化表达，而不是对任务二模型的替代。

## 7. 参数说明

本规则中，50 元/吨门槛直接沿用现行机制。其他压力分档阈值不需要在规则提取部分过度强调精确最优性，可以按照以下原则确定：

1. 参考任务二最优策略中不同执行比例出现时对应的调价压力区间；
2. 选择少数几个容易解释的整数阈值；
3. 确保规则执行后仍能明显减少大幅调价和价格路径弯折；
4. 若多个阈值表现相近，优先选择更简单、公众更容易理解的阈值。

也就是说，任务三的重点不是“阈值优化”，而是“规则提取”。阈值只是为了让规则落地。

## 8. 可用于正文的表述

为提高任务二最优策略的透明性和可执行性，本文将复杂动态调价路径整理为一套可以直接执行的简化规则，即“调价压力缓冲账户下的分档比例释放规则”。这里的“调价压力”不是抽象概念，而是指按照国际油价、汇率和现行机制计算出来的应调价格幅度，单位为元/吨。若该幅度为正，表示国内成品油价格存在上调压力；若该幅度为负，表示存在下调压力；若上一期没有完全调整，则未调整的部分继续留在压力账户中。因此，压力账户记录的是“应调但尚未完全调完的价格幅度”。

该规则不要求政策部门逐期重新求解优化问题，而是规定在每个调价窗口按照以下步骤执行。

第一，每 10 个工作日计算一次本期可释放压力。本期可释放压力由两部分组成：一是本期新增理论调幅，二是上一期压力账户余额。若本期可释放压力低于 50 元/吨，则本期不调价，并将压力继续记入账户。

第二，若本期可释放压力超过 50 元/吨，则按压力大小分档释放。压力较小时执行 25%，压力中等时执行 50%，压力较大时执行 75%，压力极大时执行 100%。因此，规则可以概括为“小幅不动，中幅慢调，大幅快调，极端全调”。

第三，本期没有释放完的压力继续进入下一期压力账户。也就是说，暂缓调价不是取消调价，部分释放也不是忽略剩余压力。未释放部分仍会在后续窗口中继续参与判断。

第四，若本期为下调且国内价格接近库存成本和合理利润底线，则下调比例降低一档；若国际油价处于高波动状态，或调价方向在连续窗口中频繁反转，则执行比例也降低一档。该规则可以概括为“高波动时慢调，成本压力较高时慎降”。

从任务二结果看，这套规则正好保留了最优策略中最重要的三个动作特征。其一，分档比例释放对应任务二中暂缓、低比例、中比例、高比例和全额执行之间的选择，使理论调幅从“必须执行的指令”转化为“逐步释放的压力信号”。其二，压力账户对应任务二中的跨期缓冲机制，使未完全释放的调价压力不会消失，而是在后续窗口继续处理。其三，下调降档和高波动降档对应任务二中成本约束下的非对称调节和预期平滑要求，使规则在传导国际成本变化的同时，避免价格过快下行冲击企业合理利润和供应安全，也减少短期波动对市场预期的放大。

因此，该规则不是对任务二模型的替代，也不是新的复杂优化模型，而是把任务二动态最优策略翻译成一套公众可以理解、部门可以执行的政策规则：先计算压力，再分档释放；未释放的压力继续记账；高波动时慢调，成本压力较高时慎降。
