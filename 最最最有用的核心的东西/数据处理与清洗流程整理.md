# 数据处理与清洗流程整理

本文档整理三问中使用的数据来源、清洗处理、时间对齐、异常值处理和主要输出文件，便于后续写论文“数据预处理”部分。

## 1. 总体处理原则

三问数据处理遵循以下原则：

1. 所有时间字段统一转为标准日期或年月格式；
2. 所有价格、调幅、数量、支出等字段统一转为数值型；
3. 对无穷值、非法字符和无法识别数值统一转为缺失值；
4. 高频日度数据按调价窗口聚合，低频月度或年度数据按“调价日前可获得信息”或年月、年份匹配；
5. 不使用未来信息。期货月度数据设置 `available_date = date + 1 day` 后再向后匹配调价日；
6. 关键中间表均输出为 CSV，供后一问直接使用。

## 2. 任务一数据处理

### 2.1 原始数据

任务一主要使用以下数据：

- Brent 日度现货价格；
- WTI 日度现货价格；
- Dubai/Oman 原油价格；
- 美元兑人民币汇率；
- 国内汽油、柴油调价记录；
- Brent、Dubai、WTI 的 M1/M3/M6 期货期限结构数据。

核心脚本：

```text
task1_serial_fusion_ridge.py
```

核心输出目录：

```text
outputs/task1_serial_fusion_ridge
```

### 2.2 国际油价和汇率处理

Brent、WTI、Dubai 和汇率数据首先统一为日度面板：

```text
date, brent, wti, dubai, usd_cny
```

处理步骤：

1. 日期列统一转为 `datetime`；
2. 油价和汇率列统一转为数值型；
3. Brent、WTI、Dubai 采用外连接合并；
4. 汇率与油价按日期合并；
5. 日度面板中缺失值使用前向填充；
6. 最后保留 Brent、WTI、Dubai 和汇率均可用的日期。

### 2.3 WTI 负值处理

2020 年 4 月 20 日 WTI 出现负值：

```text
WTI = -36.98
```

由于双因子状态空间模型需要对油价取对数，非正油价不能直接进入对数变换。因此处理方式为：

1. 原始 WTI 负值保留在原始数据中，便于追溯；
2. 状态空间建模前，将所有 `<= 0` 的油价视为缺失值；
3. 对缺失油价进行线性插值，并配合前向、后向填充；
4. 再对处理后的 Brent、WTI、Dubai 取对数。

该处理只影响状态空间模型的对数观测矩阵，不改变原始数据事实。

### 2.4 双因子状态空间数据处理

状态空间模型使用处理后的三种原油价格对数：

```text
brent_log, wti_log, dubai_log
```

处理步骤：

1. 从 2016-01-01 起截取样本；
2. 对 Brent、WTI、Dubai 中非正价格置为缺失；
3. 插值后取对数；
4. 估计基础油价状态 `state_x` 和便利收益/地缘溢价状态 `state_delta`；
5. 输出日度状态变量和综合油价状态。

若已经存在队友状态空间输出：

```text
outputs/task1_teammate_statespace/state_space_oil_index.csv
```

脚本优先读取该文件复现实验；如需重估，可使用 `--refit`。

### 2.5 国内调价数据处理

国内调价数据来自：

```text
国内柴油汽油调价/柴油汽油调价2002-2026.xlsx
```

处理步骤：

1. 将 `调整日期` 转为 `adjust_date`；
2. 将汽油价格、柴油价格、汽油涨跌、柴油涨跌转为数值；
3. 删除无调价日期记录；
4. 按调价日期排序；
5. 从 2016-01-01 起保留样本。

### 2.6 现行机制模拟窗口处理

任务一机制层保留以下规则：

- 10 个工作日窗口；
- 1 天计价滞后；
- 50 元/吨调价门槛；
- 40 美元地板价；
- 130 美元天花板价。

每个调价日处理为：

1. 本期计价结束日：

```text
pricing_end = adjust_date - 1 day
```

2. 上一轮基准计价结束日：

```text
base_pricing_end = previous_adjust_date - 1 day
```

3. 分别取截至上述日期的最近 10 条有效日度油价数据；
4. 计算本期窗口均价和上一期基准窗口均价；
5. 结合汇率均值和吨桶换算系数，计算汽油、柴油理论调幅；
6. 若绝对调幅低于 50 元/吨，则理论调幅置为 0。

### 2.7 期货期限结构处理

期货数据包括 Brent、Dubai、WTI 的 M1/M3/M6。

处理步骤：

1. 日期转为 `datetime`；
2. 期货价格转为数值；
3. 计算期限结构特征：

```text
log(M1 / M6)
log(M1 / M3)
log(M3 / M6)
```

4. 对 Brent、Dubai、WTI 的期限结构取平均；
5. 计算 M1/M6 平均期限价差变化；
6. 将月度数据的可用日期设为：

```text
available_date = date + 1 day
```

7. 用 `merge_asof` 将期货特征匹配到调价日，只使用调价日前已经可获得的数据；
8. 匹配后缺失值前向、后向填充。

### 2.8 RidgeCV 传导层特征处理

RidgeCV 使用以下特征组合做消融比较：

- 理论机制调幅；
- `state_delta` 及其窗口变化；
- 汇率变化率；
- 期货期限结构特征。

处理步骤：

1. 按调价窗口计算 `state_delta`、`state_x`、汇率均值；
2. 构造窗口变化特征；
3. 与期货期限结构特征合并；
4. 将无穷值转为缺失；
5. 缺失值使用前向填充、后向填充，最后仍缺失则置 0；
6. 按训练期和测试期评估不同特征组合。

任务一最终关键输出：

```text
outputs/task1_serial_fusion_ridge/serial_fusion_validation.csv
outputs/task1_serial_fusion_ridge/ablation_transmission_metrics.csv
outputs/task1_serial_fusion_ridge/model_description.txt
```

## 3. 任务一 1.2 和 1.3 检验数据处理

### 3.1 NARDL 非对称检验

NARDL 检验主要基于任务一第九版输出：

```text
outputs/task1_serial_fusion_ridge/serial_fusion_validation.csv
```

处理逻辑：

1. 使用调价窗口级数据；
2. 构造国际油价或机制调幅的正向、负向变化；
3. 将上涨冲击和下跌冲击拆开进入模型；
4. 对汽油、柴油分别估计短期和长期非对称；
5. 做 LR 或 Wald 检验。

稳健性实验中还尝试：

- 不同油价指标；
- 原始三油种现货价；
- 轻度平滑；
- 不同上涨/下跌门限。

关键输出：

```text
section_1_2_nardl_lr_complete.csv
section_1_2_nardl_robustness_complete.csv
```

### 3.2 区间 NARDL 检验

区间检验按油价区间划分样本，比较不同油价水平下传导机制是否变化。

处理注意：

1. 130 美元以上高油价区间样本数为 0，不适合做样本内实证；
2. 后续可采用 100 或 115 美元作为样本内高油价阈值；
3. 队友倾向使用 115 美元作为高油价区间阈值。

关键输出：

```text
section_1_3_interval_nardl_lr_tests.csv
```

## 4. 任务二数据处理

### 4.1 数据来源

任务二主要使用以下数据：

1. 任务一输出的调价窗口级数据；
2. CPI 月度数据；
3. 原油进口数量和每吨人民币成本；
4. 汽油、柴油进出口数据；
5. 汽油、柴油产量数据；
6. 居民消费支出和交通通信消费支出数据。

核心脚本：

```text
task2_dynamic_pricing_dp.py
scripts/build_gasoline_diesel_trade.py
scripts/build_apparent_consumption.py
```

### 4.2 任务一输出接入任务二

任务二读取：

```text
outputs/task1_serial_fusion_ridge/serial_fusion_validation.csv
```

主要使用字段：

- 调价日期；
- 国内汽油、柴油价格；
- 实际调价幅度；
- 任务一理论机制调幅；
- 国际油价窗口均价；
- 汇率相关变量。

处理步骤：

1. `adjust_date` 转为日期；
2. 按调价日排序；
3. 提取月份 `month`，用于匹配月度 CPI、进口成本和表观消费量；
4. 提取年份 `year`，用于匹配年度居民消费支出。

### 4.3 CPI 数据处理

CPI 数据来自：

```text
国内的一些数据/2026-2008_cpi.xlsx
```

处理步骤：

1. 将月份列改为 `month`；
2. 提取全国同比增长和环比增长；
3. 与调价窗口按 `month` 合并；
4. 缺失值使用线性插值、前向填充、后向填充。

任务二中主要使用 CPI 同比作为宏观通胀状态。

### 4.4 原油进口成本处理

原油进口数据来自：

```text
海关进出口数量数据/进口原油数量和金额_合并总表.csv
```

处理步骤：

1. 将年、月拼接为：

```text
month = 年-月
```

2. 将第一数量换算为吨：

```text
import_tonnes = 第一数量 / 1000
```

3. 直接读取 `每吨人民币` 作为：

```text
import_cost_rmb_ton
```

4. 与调价窗口按 `month` 合并；
5. 缺失值使用线性插值、前向填充、后向填充。

### 4.5 汽油、柴油进出口数据处理

进出口数据由脚本整理：

```text
scripts/build_gasoline_diesel_trade.py
```

处理步骤：

1. 自动识别汽油、柴油，进口、出口文件；
2. 支持 Excel 和 CSV；
3. 自动识别月份列或年、月列；
4. 自动识别数量列和计量单位；
5. 将数量统一换算为“万吨”；
6. 对同一月份、同一品种、同一流向求和；
7. 透视为月度宽表；
8. 缺失月份使用线性插值补齐。

输出：

```text
data/task2/gasoline_diesel_trade_monthly.csv
data/task2/gasoline_diesel_trade_long.csv
```

### 4.6 表观消费量处理

表观消费量由脚本整理：

```text
scripts/build_apparent_consumption.py
```

处理步骤：

1. 读取汽油、柴油产量数据；
2. 读取汽油、柴油进出口月度表；
3. 将所有数量统一为“万吨”；
4. 对产量、进口、出口缺失值进行线性插值；
5. 构造表观消费量：

```text
gasoline_apparent_consumption = gasoline_output + gasoline_import - gasoline_export
diesel_apparent_consumption = diesel_output + diesel_import - diesel_export
```

6. 任务二读取后，将“万吨”转换为“吨”：

```text
quantity_tonnes = apparent_consumption * 10000
```

7. 再按该月调价窗口数量分摊到每个调价窗口。

输出：

```text
outputs/task2_dynamic_pricing/task2_apparent_consumption_monthly.csv
```

### 4.7 居民消费支出处理

任务二使用：

- 全国居民人均消费支出；
- 交通通信消费支出。

处理步骤：

1. 按年份合并；
2. 数值列转为数值型；
3. 缺失值线性插值、前向填充、后向填充；
4. 构造交通通信支出占比：

```text
transport_share = transport_communication_expenditure_per_capita
                  / resident_consumption_expenditure_per_capita
```

该比例用于校准消费者福利损失权重。

### 4.8 库存成本和合理利润处理

任务二没有直接观测炼厂库存成本，因此用进口成本构造动态库存成本。

处理方式：

1. 以进口原油每吨人民币成本为基础；
2. 用本期、滞后一期、滞后二期进口成本加权平均：

```text
0.5 * 本期进口成本 + 0.3 * 上期进口成本 + 0.2 * 上上期进口成本
```

3. 加上炼化成本；
4. 炼化成本通过国内价格中位数、进口成本中位数和目标利润率校准；
5. 目标合理利润率设为 6%。

该变量进入利润保障损失和能源安全损失。

### 4.9 任务二最终模型数据表

每个油品最终形成调价窗口级数据，包括：

- `oil_price_usd_bbl`；
- `domestic_price`；
- `actual_delta`；
- `current_mechanism_delta`；
- `inventory_cost`；
- `quantity_tonnes`；
- `transport_share`；
- `cpi_yoy`；
- `cpi_mom`。

缺失关键字段的记录会被删除。

关键输出：

```text

outputs/task2_dynamic_pricing/task2_strategy_comparison_summary.csv
outputs/task2_dynamic_pricing/task2_window_loss_breakdown.csv
```

## 5. 任务三数据处理

### 5.1 规则提取数据

任务三不重新收集原始数据，主要使用任务二 baseline 输出：

```text
outputs/task2_dynamic_pricing/task2_all_fuels_optimal_strategy.csv
```

核心字段：

- `mechanism_delta`：任务二中的基准理论调幅；
- `optimal_ratio`：任务二滚动优化选择的执行比例；
- `optimal_delta`：任务二最优调价额；
- `carry_over_next`：任务二结转项；
- `inventory_cost`：库存成本；
- `oil_price_usd_bbl`：国际油价；
- 各类损失分解。

任务三将 `mechanism_delta` 理解为本期新增调价压力，将未释放部分记入压力账户。

### 5.2 简化规则数据处理

简化规则不重新拟合模型，而是按任务二输出构造可执行规则：

1. 读取 baseline 调价窗口数据；
2. 对汽油、柴油分别处理；
3. 计算本期可释放压力：

```text
本期可释放压力 = 本期新增理论调幅 + 上期压力账户余额
```

4. 按 50、150、300、500 元/吨分档；
5. 得到 0、25%、50%、75%、100% 执行比例；
6. 未释放部分进入下一期压力账户；
7. 下调时若接近成本和合理利润底线，则降低一档；
8. 高波动或方向反转时，也降低一档。

### 5.3 高斯扰动稳定性检验数据处理

最终采用的鲁棒性检验脚本：

```text
task3_rule_stability_under_noise.py
```

检验对象不是现行机制，而是同一条简化规则在扰动前后效果是否稳定。

处理步骤：

1. 读取任务二 baseline 结果；
2. 对汽油、柴油分别计算历史国际油价对数收益率标准差；
3. 对每个调价窗口的国际油价水平加入独立高斯扰动：

```text
ln P_t^sim = ln P_t + epsilon_t
epsilon_t ~ N(0, sigma_noise^2)
sigma_noise = 0.1 * sigma_historical
```

4. 为避免小扰动累积成趋势，扰动直接加在油价水平对数上，而不是加在收益率上；
5. 扰动后油价限制在合理范围：

```text
8 <= simulated_oil_price_usd_bbl <= 180
```

6. 将油价扰动换算为理论调幅扰动：

```text
added_delta = 50 * (simulated_oil_diff - base_oil_diff)
```

其中 1 美元/桶约折算为 50 元/吨；

7. 同步调整库存成本：

```text
simulated_inventory_cost = inventory_cost + 50 * (simulated_oil - base_oil)
```

8. 每个油品重复模拟 500 次；
9. 将扰动路径下的简化规则指标与无扰动基准比较。

### 5.4 任务三鲁棒性输出

主要输出：

```text
outputs/task3_rule_extraction/task3_rule_stability_baseline.csv
outputs/task3_rule_extraction/task3_rule_stability_noise_simulations.csv
outputs/task3_rule_extraction/task3_rule_stability_detailed_changes.csv
outputs/task3_rule_extraction/task3_rule_stability_summary.csv
outputs/task3_rule_extraction/任务三_简化规则高斯扰动稳定性检验.md
```

其中：

- `baseline.csv`：无扰动下简化规则指标；
- `noise_simulations.csv`：500 次扰动模拟结果；
- `detailed_changes.csv`：每次扰动相对无扰动基准的变化；
- `summary.csv`：按油品汇总的鲁棒性结果；
- Markdown 报告用于论文写作。

```text
        ↓

        ↓

```

## 7. 最需要在论文中说明的清洗点

论文中建议重点说明以下数据处理：

1. WTI 负值在状态空间取对数前作为缺失值插值处理；
2. 日度油价与调价窗口通过 10 个工作日窗口和 1 天滞后对齐；
3. 月度期货数据使用 `available_date` 向后匹配，避免未来信息泄露；
4. CPI、进口成本、居民支出等低频数据按月或年匹配，并对缺失值插值；
5. 汽油、柴油需求量使用产量 + 进口 - 出口构造表观消费量；
6. 库存成本由进口成本加权平均和炼化成本校准构造；
7. 任务三高斯扰动直接加在油价水平对数上，检验简化规则扰动前后效果是否稳定。
