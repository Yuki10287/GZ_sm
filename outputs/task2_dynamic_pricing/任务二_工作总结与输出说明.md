# 任务二工作总结与输出说明

任务二主要完成的是：在任务一给出的“理论机制调幅”基础上，构建一个动态调价优化模型，让政府在每个调价窗口选择实际执行多少调幅，从而在民生、企业利润、CPI、预期稳定、能源安全之间做综合权衡。

## 一、最后采用的主模型

主脚本为：

```text
task2_dynamic_pricing_dp.py
```

虽然文件名中有 `dp`，但最终主模型不是严格值迭代，而是有限期滚动优化模型。

每个调价窗口向前看 3 期：

```text
H = 3
```

动作空间是任务一理论调幅的比例执行：

```text
ratio_grid = [0, 0.25, 0.5, 0.75, 1.0]
optimal_delta = ratio × current_mechanism_delta
```

模型同时保留：

```text
50 元/吨调价门槛
carry_over 结转机制
库存成本与合理利润约束
CPI 滞后传导
价格预期平滑损失
能源安全分段惩罚
```

因此，最后的最优策略不是某一个固定数值，而是一套逐窗口动态策略：

```text
每个调价窗口根据理论调幅、上一期结转、库存成本、国内价格、CPI 状态和上一期调幅，
在 0%、25%、50%、75%、100% 中选择一个执行比例，
得到该期 optimal_delta。
```

## 二、最后最优策略的核心特征

最优策略可以概括为三点。

第一，分档释放。

理论调幅不是直接全额执行，而是按 0%、25%、50%、75%、100% 分档执行。

第二，跨期缓冲。

低于 50 元/吨或暂未执行的调价压力会进入 `carry_over`，在后续窗口继续消化。

第三，成本约束下的非对称调节。

在库存成本压力较大时，下调更谨慎，上调保留必要传导，避免价格长期低于成本和合理利润基础。

## 三、核心结果

基准情景下，汽油结果为：

```text
历史实际平均总损失：0.077450
现行机制平均总损失：0.068676
最优策略平均总损失：0.027829
相对现行机制下降：59.48%
现行机制平均绝对调幅：199.90 元/吨
最优平均绝对调幅：117.93 元/吨
大幅调价次数：9 次降到 3 次
```

柴油结果为：

```text
历史实际平均总损失：0.075733
现行机制平均总损失：0.063517
最优策略平均总损失：0.027155
相对现行机制下降：57.25%
现行机制平均绝对调幅：190.28 元/吨
最优平均绝对调幅：113.70 元/吨
大幅调价次数：9 次降到 3 次
```

五维损失中，最主要改善来自价格预期平滑损失。

汽油：

```text
机制预期损失：0.385506
最优预期损失：0.069591
下降约 81.95%
```

柴油：

```text
机制预期损失：0.353482
最优预期损失：0.064588
下降约 81.73%
```

需要注意的是，最优策略不是五个维度全部改善。消费者福利、企业利润保障、能源安全分项在基准情景下有所上升。因此，论文中应表述为：

```text
社会总福利加权意义下的最优折中
```

而不是“五个目标全部更优”。

## 四、主要输出文件说明

### 1. 基准情景总结结果表

```text
outputs/task2_dynamic_pricing/task2_strategy_comparison_summary.csv
```

代表：基准情景下，汽油和柴油分别的历史实际、现行机制、最优策略的总损失、五类损失均值、平均调幅、调幅标准差、大幅调价次数等。

这是任务二最重要的汇总表。

### 2. 多政策情景对比表

```text
outputs/task2_dynamic_pricing/task2_strategy_comparison_summary_by_scenario.csv
```

代表：不同政策偏好情景下的结果，包括：

```text
baseline
livelihood_priority
stability_priority
security_priority
```

可用于说明不同权重下最优策略如何变化。

### 3. 最优逐窗口调价结果

```text
outputs/task2_dynamic_pricing/task2_all_fuels_optimal_strategy.csv
```

代表：汽油、柴油每一个调价窗口的实际调价、机制调价、最优调价、最优执行比例、结转、价格、五类损失等。

如果需要查看“每一期最优调多少”，应查看这个文件。

outputs/task2_dynamic_pricing/task2_all_fuels_optimal_strategy_by_scenario.csv

## 五、一句话总结

任务二最后得到的是一套基于任务一理论调幅的动态比例执行策略：每期不是机械全额执行机制调幅，而是在 0%、25%、50%、75%、100% 中选择最优执行比例，并通过 50 元门槛、结转机制和成本约束平滑调价路径。它显著降低了社会总福利损失，尤其改善了价格预期稳定性，但代价是部分消费者、企业利润和能源安全分项损失有所上升。
