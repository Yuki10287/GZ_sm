模型版本整理总说明

本目录按版本整理了当前任务一尝试过的主要模型。每个子目录包含：

1. 对应 Python 脚本副本；
2. 模型说明.txt；
3. 输出结果文件夹。

注意：
子目录里的 Python 脚本主要用于阅读和归档。由于脚本中的数据路径按项目根目录组织，若需要重新运行，建议回到项目根目录运行对应脚本。

各版本说明：

01_优化机制模型_PCA_Kalman窗口均价
基础主模型。用 Brent/WTI/Dubai 构造 PCA+Kalman 国际基准油价，再用本窗口10日均价对比上一窗口10日均价模拟现行调价机制。

02_队友原公式对照模型
尽量保留队友原调价控制公式，即本窗口均价对比窗口首日价格。该版本用于对照，效果较差。

03_严格双因子状态空间模型
严格实现队友最初的 X_t + delta_t 双因子状态空间模型，并接队友原控制层。该版本数学形式完整，但实证效果较差。

04_改良双因子状态空间_修正控制层
保留双因子状态空间层，但把调价控制层修正为上一窗口均价基准、1天滞后和硬阈值规则。效果明显改善。

05_多源动态因子状态空间模型
使用多源动态因子状态空间模型，比较原油、汇率、海关和宏观变量的消融效果。该版本效果最好或接近最好，适合作为增强模型。

06_WTI期货期限结构增强双因子模型
加入 PET_PRI_FUT_S1_D.xls 中 WTI M1-M4 期货期限结构，尝试改进双因子模型。理论上更完整，但当前样本中没有提升效果。

07_真实M1M3M6期限结构增强双因子模型
使用队友整理后的 期货数据/futuredata.xlsx，加入 Brent、Dubai、WTI 三油种真实 M1/M3/M6 期限结构。模型把现货价格水平用于识别基础油价 X_t，把近远月价差 log(M1/M3)、log(M1/M6)、log(M3/M6) 用于识别 delta_t，并用向后填充避免月度数据未来信息泄露。该版本比直接堆期货价格水平更合理，但受 2026 年异常期限结构影响，整体稳定性仍弱于主模型，适合作为扩展实验。
